# B44 世界观地名校正

本批次遵循“静态地名中性化、政治京号事件化”的原则，不把全图机械回退到春秋
地名。只处理三类问题：依赖本世界线不存在的帝王或王朝事件、明显晚于 1444 年
的现代行政名，以及显示名、定义名、首府和国家归属相互串线的省份。

- 权威映射：`toponym_manifest.csv`
- 幂等事务：`tools/map_pipeline/apply_b44_worldview_toponyms.py`
- 执行报告：`apply_report.json`
- 地图策略：不改 `provinces.bmp`、RGB、Area、Region、贸易节点、地形或位置。
- 历史文件策略：为继续遮蔽依赖的精确 VFS 路径，拉丁文件名允许保留旧名；
  `definition.csv`、初始 `capital` 与 `localisation/replace` 才是当前语义权威。

## 江宁—六合最终裁决

- 1821 是原南京地图槽位，固定为江宁：吴国 `WUU`、吴越文化、`7/8/4`，
  并保留吴国固定首都和全部南京奇观。
- 5056 是新增的六合：徐侯国 `XU2`、江淮文化、`2/2/1`，不承载任何奇观。
- 两省商品、宗教、要塞、日期历史、地图像素和总发展度保持不变。
- 该裁决是用户按地图位置作出的最终修正，优先于此前所有反向解释。

## 京号规则

地图默认使用蓟、江宁、开封、洛阳等城邑名。北京、南京、东京、西京等方向性
京号不作为永久静态省名；如未来有国家称帝或建立多京制，应由决议或事件授予。
“东京开封”“成周”等周廷称号仍可存在于政治叙事中，地图省名保持开封、洛阳。
