# B48 开局贸易中心层级重构

## 结论

重构前共有 38 个开局贸易中心：一级 20、二级 17、三级 1。总密度并非主要问题，问题是成都、西安、杭州节点的二级中心比例过高，以及闽南、珠江口、淮扬等局部重复布点。

重构后保留 32 个：一级 22、二级 9、三级 1。

- 三级：只保留广州，代表全国级海贸门户。
- 二级：每个大节点只保留少数骨干枢纽。
- 一级：用于区域集散、河运节点、山口和边贸。
- 撤销：香山、南雄、衡州、厦门、淮安、寿州。
- 降级：太原、大理、昆明、重庆、开封、兰州、芜湖。

撤销中心并不删除城市、省份或贸易节点成员，只移除开局贸易中心修正。完整政策和节点配额见 `batch_manifest.json`。
