# 汉地不可通行山脉：战略核心初稿

本批次只产出评审文件，不修改正式 `map/provinces.bmp`，也不提前写入
`definition.csv`、`climate.txt`、`terrain.txt` 或本地化。

## 设计取舍

- 以本 Mod 当前地图为底图，沿用已经实装的秦岭、大巴山、岷山、陇山及山西山系。
- 以“大明日不落”的连续山系轮廓为主轴，以“风云世纪两千年”的燕山东西分段补足北方屏障。
- 新增轮廓贴合当前省界，并限制对任一可通行省份的侵占。
- 天目、仙霞、九岭、大洪等次级山丘保留为普通山地，不设为不可通行，避免江南通路过碎。

## 五组山系与预留走廊

### 燕赵晋秦

燕山东西段控制草原进入燕都的方向，但正式实装时保留宣府、古北和山海关三条入口。
恒山—太行—吕梁—中条形成山西高原边缘，保留井陉、滏口及河东—河洛通道。
秦岭、陇山与伏牛山控制关中、汉中、河洛、南阳之间的交通，保留陈仓、武关和宛洛方向。
陕州不作为封闭盆地处理：保留它与华州、洛阳的直接陆地邻接，但不单独绘制关道，
从而成为河洛与关中之间必须争夺的关门省份。

### 江汉屏障

桐柏—大别山把江汉、淮西和中原分成不同进攻方向，但不封死信阳及长江沿岸。
巫山、大巴山构成四川盆地东缘；长江可通航河段应继续成为三峡方向的主要通路。

### 东南脊梁

武夷、罗霄、雪峰和南岭让江西、福建、湖南、两广之间需要选择山口，而不是任意横穿。
正式实装时应至少保留赣江—南雄、湘桂、梧州西江及闽江谷地等主要走廊。

### 西南高地

大凉山、哀牢山、苗岭、大娄山和岷山用于区分四川盆地、云贵高原与滇西河谷。
这些山系只做方向性阻隔，不围死成都、昆明、贵竹或大理等区域。

### 齐鲁山地

泰山作为小型战略核心，区分济南、青州与曲阜方向；鲁西平原和胶东方向保持通畅。

## 正式实装前置条件

1. 为 18 段新增候选分配正式省份 ID 与唯一 RGB。
2. 将每段分别写入 `definition.csv`、`climate.txt`、`terrain.txt`、`continent.txt` 和本地化。
3. 不可通行省份不创建普通省份历史，也不加入区域、贸易节点或贸易公司。
4. 对每条预留走廊进行陆路寻路测试；若使用特殊 crossing，必须具有真实山口或河谷依据。
5. 再次检查所有山脉为单一四向连通块，并确认正式地图外部像素变化为零。
