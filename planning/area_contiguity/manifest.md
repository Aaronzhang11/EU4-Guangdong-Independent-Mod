# B31 汉地区域陆地连通重排

- 目的：让汉地普通大陆 `area` 的省份通过四向陆地边界连成一块。
- 修改范围：`map/area.txt` 与三个受组成变化影响的区域本地化。
- 不修改：`provinces.bmp`、RGB、定义、发展度、历史、地形、贸易节点、区域所属 region。
- 空引用：移除已无地图像素的怀庆 692、瓜州 5298。
- 明确例外：昌国群岛（岛屿机制）；三镇（长江、汉江世界观设计）。
- 正式备份：`planning/area_contiguity/pre_b31_area.txt` 及对应本地化源文件。

## 关键重排

- 易州仍属冀南；保定由冀中转入冀南，连接易州—真定。
- 阿坝与松茂交换汶川、若尔盖。
- 滇南与滇西南交换版纳、勐腊、思茅、镇沅。
- 湖南三组重新排列，保持湘中与湘西南岭各四省。
- 荆宜施南、汉水襄郧、巴东、洞庭湖进行边界联动重排。
- 芜湖转入徽宁，皖江保留安庆—池州—无为连续核心。
- 商州转入长安；静宁、巩昌在陇南与陇东之间互换。
