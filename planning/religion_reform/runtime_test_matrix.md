适用边界：EU4 1.37.x、当前 `religion` 分支、新开 1444 战役；默认不兼容旧版本存档。
目标：证明“诸子临朝—培植—正式更张—新旧相攻—成功／强推／复旧—清理”是一条可保存、可恢复、不可绕过的完整状态机。

2026-08-28 的受邀法家主流程、成功结算、失败双出口、迎还旧学、低分辨率显示、日志和无夹具清洁启动证据见
[`docs/gameplay/runtime_evidence/doctrine_reform_2026-08-28/README.md`](../../docs/gameplay/runtime_evidence/doctrine_reform_2026-08-28/README.md)。未在该证据中明确列出的行仍保持 `PENDING`，不得据此宣称整个矩阵已经完成。

> 本文件是测试计划，不是测试完成证明。只有某一行留下截图、日志差分和存档／控制台步骤，并把结果标为 `PASS`，才算该路径已有实机证据。

## 1. 验收纪律

- 每轮只验证一个明确边界；优先使用新开局或隔离存档。
- 测试前记录基线 `error.log`、`game.log`、`setup.log`，测试后只归因新增内容。
- 需要加速五年或十年计时，可使用临时、显式、易清理的测试事件，但不得把它接入 `on_startup`、年度脉冲或生产决议。
- 截图必须同时覆盖触发入口、可见国家修正／宗教页状态和关键事件结果；检查中文长文本无裁切、选项无溢出、徽章无堆叠。
- 每轮结束通过菜单正常退出 EU4，并确认进程已经关闭。
- 最终清理所有测试事件、控制台脚本、临时本地化、无条件日志断言和启动注入，再跑静态验证与一次无夹具的新开局冒烟。

## 2. 设计真值

| 项目 | 首版契约 |
|---|---|
| 首次立论 | 唯一“召集诸子百家”决议；“诸子临朝”两页六家，选中后确认，以 `25` 践履立论 |
| 暂不立论 | 退出并获得 `2` 年暂缓冷却 |
| 更张根基 | 目标为当前正式宾学契约对应的第二学派（匹配受邀修正、总契约旗标与学派旗标，且契约至少还剩 `5` 年），或境内有该派活跃具名学宫；学宫根基不受宾学余期限制 |
| 培植 | `5` 年；叛乱 `+1`、稳定花费 `+15%`、顾问花费 `+15%` |
| 正式更张 | 稳定 `-1`、威望 `-25`、新主学派践履设为 `15` |
| 新旧相攻 | `10` 年；叛乱 `+2`、稳定花费 `+25%`、治理容量 `-10%`、税收 `-10%`、人力恢复 `-10%` |
| 成功 | 十年到期时践履 `>=50` 且稳定 `>=1`；获得 `10` 年“新政既定” |
| 新政既定 | 叛乱 `-1`、稳定花费 `-10%`、改革进度 `+15%`、顾问花费 `-10%` |
| 平淡结算 | 践履 `25—49`，或践履 `>=50` 但稳定 `<1`；无奖励，进入 `10` 年冷却 |
| 失败 | 践履 `<25`；必须显示“强推新学／迎还旧学”两个出口 |
| 强推 | 再承受政治代价并延长 `5` 年；延长期不再发成功奖励，结束后进入 `10` 年冷却 |
| 复旧 | 旧学复主、新学退居第二槽、旧学践履 `25`；不额外扣稳定；`15` 年更张冷却 |
| 朝令夕改 | `10` 年：君主点花费 `+5%`、改革进度 `-25%`、外交声誉 `-1`、稳定花费 `+20%` |
| 邀请锁 | 培植和新旧相攻期间不得邀请／替换第二学派；过渡结束后恢复，且不受更张冷却影响 |
| 宾学契约 | 确认后支付 `75` 外交点与半年收入，契约 `20` 年且同一时间只能有一家；前 `5` 年承受磨合，期满可续聘或礼送，亦可付重价提前逐客 |
| 天下大辩 | 培植中不能提案或成为主议国；已开大辩仍按入场旧学投票；成熟时有大辩则延后；正式更张清掉旧提案／请辩资格 |
| 改宗清理 | 离开礼教立即清理整条更张状态；改回礼教后无主学派，重新走首次立论 |
