# B61 边疆与域外政权旗帜

本批次为诸夏文化圈之外、但处于当前东亚世界观主要舞台内的 28 个政权建立独立旗帜语言。

设计原则：

- 诸夏国家继续使用小篆印章体系；本批国家改用山川、日月、动物图腾、铜鼓、织锦与塔木加。
- 不直接套用近现代民族国家旗帜，也不把所有边疆政权处理成单字旗。
- 采用粗轮廓、强色块和有限色板，保证 128×128 原图缩入 EU4 盾徽后仍可识别。
- 箕子朝鲜虽然地理位于半岛，但在本世界观中属于诸夏封邦，因此不纳入本批重绘。
- 高丽是独立的三韩后继政权，使用青瓷绿、山海与日轮；曷懒使用女真猎鹰；辽使用契丹白鹿。

生成与校验：

```bash
python3 tools/generate_frontier_polity_flags.py
python3 tools/generate_frontier_polity_flags.py --check
```

完整的色板、纹样和世界观理由保存在 `batch_manifest.json`；总览见 `contact_sheet.png`。
