# B45 湖南—江西平衡细化

本批按用户审定的统一效果图实施，不照搬《岁在甲子》的全部省界，只把其边界
作为十一组母省内部的参考。正式地图保持所有母省外边界不变。

## 数量与区域

- 湖南：12 省调整为 23 省，新增 11 省。
- 江西：10 省调整为 16 省，新增 6 省。
- 湖南 Area：武陵、澧水、洞庭、长沙、衡郴、湘沅。
- 江西 Area：浔阳、豫章、庐陵、赣南。
- 公安（5014）移入荆夔 Area，不再割裂洞庭。

## 国家平衡

长沙国仅有长沙（671）、湘潭（4998）、浏阳（5321），合计 27 发展度。
岳州和平江归楚；澧水—洞庭西北归武陵；湘西归辰州苗蛮；衡州、耒阳、
茶陵、郴州、宝庆、永州及南部门户连州组成新国家“衡”。因此细化不会把湖南
的额外省份和发展度全部送给长沙。

江西维持多国格局：南昌、楚、临川、天师府和客家分别控制相邻的小型板块。

## 可重放事务

正式入口：

```sh
python3 tools/map_pipeline/apply_b45_hunan_jiangxi_refinement.py
python3 tools/map_pipeline/apply_b45_hunan_jiangxi_refinement.py --check
```

`pre_b45_provinces.bmp` 只用于冻结可编辑母省掩膜；重放时脚本仅覆盖该掩膜，
不会用旧备份重建整张地图。`batch_manifest.json` 记录精确 ID、RGB、像素数、
国家发展度和验证结果。
