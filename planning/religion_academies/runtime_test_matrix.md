# 具名学宫生命周期：实机验收矩阵

## 0. 文档性质与通过口径

本文是**待执行的实机验收计划**，不是已经取得的实机证据。测试目标为全新
`1444.11.11` 战役；不验证旧存档迁移。正式证据沿用现有目录格式，放在：

```text
docs/gameplay/runtime_evidence/academy_lifecycle_YYYY-MM-DD/
├── README.md
├── 01_1444_academy_placements.png
├── 02_foreign_school_tension.png
└── ...
```

证据目录的 `README.md` 至少记录：EU4 版本、分支、被测提交、测试国家与省份、
每项的期望／实测／结论、日志结论，以及正常退出后 EU4 进程已关闭。截图必须能看清
相关悬停、日期、国家或省份；不得用控制台挡住被验收控件。

生命周期的权威状态只有以下几类：

- 活跃学宫：某省份唯一的永久修正 `zhx_academy_<key>`；
- 流散学宫：不存在上述活跃修正，同时存在全局旗标
  `zhx_academy_dormant_<key>`；
- 学宫遗址：原址永久修正 `zhx_academy_ruins_<key>`，它不是活跃学宫；
- 逐学过程：国家修正 `zhx_academy_expulsion_campaign`、一个
  `zhx_academy_expelling_<key>` 国家旗标，以及目标省份修正
  `zhx_academy_under_expulsion`；
- 待接纳邀约：候选国旗标 `zhx_academy_refuge_offer_pending` 与恰好一个
  `zhx_academy_refuge_offer_<key>`。

任何一次迁移都必须满足：同一固定专名在世界上至多一座活跃学宫；遗址可以保留，
但不得同时充当活跃学宫。

### C. 到期迁移、候选优先级与流散

以下各项应从 B01 的正式逐学状态进入 `.200`。为了缩短重复分支测试，可以在状态已完整建立后
执行 `event zhx_academy.200 PROVINCE_ID`；这只替代等待，不替代 B02 的一次自然三年验收。

候选优先顺序是：

1. 奉行该派为主学派的礼教国家；
2. 没有第一类时，已邀请该派为第二学派的礼教国家；
3. 前两类均不存在时，对逐学国意见至少 `+50` 的其他礼教国家。

逐学国自身永远不是候选。每一层内部随机选一个有空闲城市、且没有 pending offer 的国家。
未获保护的玩家逐学国会在 `.200` 后收到自己的 `.220` 离境回执；它与候选国收到的
`.210` 求庇事件是两张不同事件，截图必须分别留存，不能相互替代。

| 编号 | 场景与最短步骤 | 通过条件 | 最低证据 |
|---|---|---|---|
| C01 | 到期时保留至少一个同派主学派候选；确保另有第二学派与友好候选 | `.210` 只发给同派主学派层；不得落到第二或友好层；若逐学国为玩家，另收到 `.220` 且两张事件专名一致 | 到期前候选条件表、逐学国 `.220`、候选国 `.210` 与学派截图 |
| C02 | 在一次性分支档中排除所有同派主学派候选，仅保留一个已邀请该派的候选 | `.210` 发给第二学派候选；友好候选不能越级 | 候选第二学派徽章／修正与 `.210` |
| C03 | 排除所有同派主学派和第二学派候选，仅保留一个对逐学国意见至少 +50 的礼教候选 | `.210` 发给友好候选；候选对逐学国的意见方向必须正确 | 外交意见悬停与 `.210` |
| C04 | 候选国同时有合格空城：至少一座发展度 ≥20、一座 12—19、一座 <12；在 `.210` 选“接纳” | 新址必在任一发展度 ≥20 的空闲城市。规则是**优先层级内随机**，不要求绝对最高发展度；若无 ≥20 才允许 12—19，二者皆无才可落任意空城；玩家候选国安装成功后同步收到 `.211` | 接纳前城市清单、完整 `.211` 回执与回执所指新址悬停 |
| C05 | 在同一接纳分支检查原址与新址 | `.211` 正确显示固定专名与实际新省份；原址移除活跃学宫并留下对应永久遗址；新址出现同一个固定专名；国家协同／张力随新持有国刷新；遗址省份不能成为任何后续学宫新址 | 完整 `.211`、原址遗址、新址活跃学宫、候选国国家修正 |
| C06 | 从到期前存档重载；在 `.210` 先悬停“婉拒其请”，再点击拒绝 | 悬停明确说明学宫不会迁入、不会删除、保持流散，天子每年有 `10%` 复兴尝试且无合格礼教国家接纳时继续流散；点击后 pending／专名 offer 旗标清空，世界上没有该专名活跃学宫，对应 dormant 全局旗标保留，原址遗址仍在 | 完整拒绝选项悬停、拒绝后世界／存档状态、原址遗址 |

#### C01—C03 的确定性要求

正常 1444 世界中同派国家很多，随机接受国不足以证明三层优先级。若通过普通外交和改派无法快速
隔离候选池，可以增加一个**只供本地测试、只由控制台触发、没有 on_action 的临时 setup 事件**：

- 它只能清理测试档中的候选主学派／受邀修正、设置指定候选关系与资源；
- 迁移本身仍必须由生产事件 `.200` 调用生产候选选择，再由生产事件 `.210` 接纳；
- 不得在临时事件中直接安装学宫，否则不能证明候选优先级；
- 临时文件建议统一使用 `zzz_zhx_academy_runtime_test_*` 文件名与
  `zhx_academy_rt` namespace，并在证据 README 列明用途；
- **测试结束必须删除事件、临时 opinion modifier、本地化、决议及任何 startup／on_action 注入，
  重新编码本地化并确认生产目录不再含这些测试键。临时注入不得提交。**

若没有完成候选池隔离，C01—C03 必须标为“未验收”，不能仅凭代码阅读判通过。
