# 文档地块文化映射裁决

本目录中的 CSV 是《全地块文化（几乎所有汉地及周边）(3).docx》的持久化、按省份 ID 消歧后的批准输入。它只记录最终文化目标，不直接修改游戏文件。

## 输入约定

- province_id 是唯一执行键；中文名称只用于人工复核。
- 优先级为：用户后续明确覆盖 > 文档明列地块 > “全境”范围规则 > 补充兜底。
- 每个省份 ID 只出现一次；执行脚本不得再按中文名称猜测或扩展。
- 文档中的顺庆、青州重复项各折叠为一行；秦安冲突按批准裁决只保留 5276 -> gdd_long。

## 关键同名与别名裁决

- 原始 DOCX 的“汉文化组、百越文化组、殷商文化组、羌文化组”仍保留在 CSV 的来源标签中，便于追溯；最终游戏界面显示名按用户后续裁决统一为“诸夏、百越、殷商、羌”。内部键 `east_asian`、`gdd_baiyue_group`、`korean_g`、`gdd_qiang_group` 不改，以保持既有机制兼容。

- 通州：江淮 5022，河北 5115；宁海：齐鲁 5106，吴越 5005。
- 剑川：巴蜀条目解释为剑州 5081，白文化剑川为 5226。
- 南京语义地块仍为 5056，六合仍为原南京槽位 1821；用户后续明确要求两者互换文化与三项发展度，因此最终为 1821 -> gdd_wu、5056 -> gdd_jianghuai，发展度分别为 7/8/4 与 2/2/1。贸易品、城堡、首府及南京专属机制不交换。
- 壮侗文化的广宁、兴化分别为安南地块 4819、4820，不是辽宁 5207 或福建 4952。
- 文昌按批准别名映射海南万州 5303；松曲映射松州 2170；麟州映射鄜州 5268。
- 其他已固化别名包括：西安→长安 700、阜阳→颍州 2144、商丘→归德 2176、合川→合州 5026、淄博→临淄 5104、镇定→真定 4195、热河→承德 703、玉林→鬱州 5202、福州→闽侯 669、建昌→嶲州 2748。
