# B73 朝鲜贸易节点

本批次把 `korea_region` 的七个区域、共30个可玩省份从日本节点和日本特许公司中完整拆出：

- 贸易节点：`korea`，显示名“朝鲜”；
- 特许公司：`trade_company_korea`，显示名“朝鲜特许公司”；
- 贸易流：`朝鲜 → 日本 → 吴越`；
- 朝鲜节点盾牌：朝鲜湾（1375）；
- 日本节点盾牌：移至天草海（1389）；
- 朝鲜湾只作为节点显示锚点，不进入特许公司范围。

权威范围始终从当前 `map/area.txt` 的七个朝鲜区域派生。终端重放命令：

```bash
python3 tools/map_pipeline/apply_b73_korea_trade.py
```
