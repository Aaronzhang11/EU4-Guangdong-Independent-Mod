## 1. 文件准备

不要直接在正式 `map/provinces.bmp` 上开始练习。

准备三个层级的文件：

```text
candidate_baseline.bmp
working.psd
candidate_v1.bmp
```

用途：

| 文件 | 用途 |
|---|---|
| `candidate_baseline.bmp` | 未修改基线和回退备份 |
| `working.psd` | 保留分层编辑能力 |
| `candidate_v1.bmp` | 用于审计和游戏测试 |
| `candidate_v2.bmp` | 后续修改版本 |

永远不要覆盖唯一的未修改基线。

## 2. Photoshop文档设置

打开候选BMP后检查：

```text
图像 → 模式 → RGB颜色
图像 → 模式 → 8位/通道
```

确认：

- 宽度为5632像素；
- 高度为2048像素；
- 未改变图像尺寸；
- 未执行重采样；
- 未转换为索引色；
- 未添加透明通道。

打开BMP时，如果Photoshop询问颜色配置文件，不要执行会改变像素RGB数值的转换。

## 3. 图层设置

立即另存为：

```text
working.psd
```

每个新山体建立独立图层，例如：

```text
5310_南岭西段
5311_南岭东段
```

要求：

- 图层模式为“正常”；
- 图层不透明度为100%；
- 填充为100%；
- 不使用图层效果；
- 不使用混合模式；
- 不使用蒙版模糊边缘；
- 不变换或缩放山体图层。

导出前确认所有需要写入的山体图层都处于可见状态。

## 4. 铅笔工具设置

长按工具栏中的画笔工具，选择：

```text
铅笔工具
```

顶部设置：

```text
模式：正常
不透明度：100%
大小：1像素
自动抹除：关闭
```

禁止使用：

- 普通画笔；
- 柔边笔刷；
- 喷枪；
- 形状工具；
- 矢量直线；
- 半透明；
- 羽化；
- 抗锯齿；
- 模糊；
- 涂抹；
- 内容识别填充。

先使用1像素铅笔确定边界，再手工向内部加厚。

## 5. 设置精确RGB

Photoshop左侧工具栏底部有两个重叠色块。

点击前面的色块，即“前景色”，打开：

```text
拾色器（前景色）
```

输入精确RGB，或输入十六进制颜色。

示例：

### 5310

```text
R：37
G：173
B：211
HEX：25ADD3
```

### 5311

```text
R：198
G：52
B：122
HEX：C6347A
```

设置后点击“确定”。

前景色只是铅笔当前使用的颜色，不会自动填充整个图层。

不要凭肉眼在颜色面板中拖动选择近似色。

## 6. 坐标与像素网格

打开：

```text
窗口 → 信息
视图 → 标尺
视图 → 显示 → 像素网格
```

在标尺上右键，将单位设为：

```text
像素
```

如果标尺原点被移动，双击左上角两条标尺的交叉点，将原点恢复到图像左上角。

建议缩放：

```text
1600%
3200%
```

信息面板用于查看鼠标位置：

```text
X
Y
RGB
```

定位困难时，使用：

```text
视图 → 新建参考线
```

按像素坐标添加水平或垂直参考线。

## 7. 绘制山体

绘制顺序：

1. 选择对应山体图层；
2. 设置正确前景色；
3. 找到需要阻断的省份公共边；
4. 先沿公共边的一侧绘制1像素轮廓；
5. 检查是否覆盖整条目标公共边；
6. 向指定母省内部加厚；
7. 保持约3—5像素的稳定宽度；
8. 检查山体是否上下左右连通；
9. 检查是否误入其他省份；
10. 检查是否碰到城市或港口锚点。

优先从面积较大的省份让出山体像素，避免把面积较小的可通行省份切碎。

山体可以弯曲，但不能只依靠对角线连接。

## 8. 保留通道

山体经过两个省份之间，不一定必须封死道路。

需要保留通行时：

- 不覆盖全部公共边；
- 保留连续的上下左右接触；
- 不只留下一个脆弱像素；
- 不依靠对角线；
- 将道路位置记录到设计表；
- 后续使用邻接审计确认公共边仍然存在。

如果只需要表现“有山但仍可通行”，可以：

- 在 `provinces.bmp` 中保留两省接壤；
- 后续在 `terrain.bmp` 中绘制山地外观；
- 不用不可通行省份完全隔开两省。

## 9. 修改和擦除

如果山体画在独立图层上：

1. 选择对应山体图层；
2. 按 `E` 选择橡皮擦；
3. 将模式设为“铅笔”；
4. 大小设为1像素；
5. 不透明度设为100%；
6. 擦除错误像素。

擦除透明图层后，下方原始省份颜色会重新显示。

不要用白色覆盖错误像素。

如果错误内容刚刚绘制，可以使用：

```text
Ctrl+Z
```

通过开关图层前面的“眼睛”，对比山体绘制前后的原始边界。

## 10. 导出BMP

先保存PSD：

```text
Ctrl+S
```

确认需要导出的山体图层全部可见，然后选择：

```text
文件 → 存储副本
```

不要使用“导出为”。

文件名采用版本化命名：

```text
candidate_v1.bmp
candidate_v2.bmp
```

BMP选项：

```text
文件格式：Windows
位深：24位
压缩：无
```

如果Photoshop提示是否合并图层，只对导出的BMP副本执行合并，保留PSD中的原始图层。

## 11. 导出后检查

重新打开导出的BMP，确认：

```text
图像 → 模式 → RGB颜色
图像 → 模式 → 8位/通道
```

检查：

- 图像仍为5632×2048；
- 新山体颜色保持精确RGB；
- 没有透明区域；
- 没有抗锯齿杂色；
- 没有额外颜色；
- 两个山体图层都已经写入BMP；
- 未修改区域与基线完全一致；
- 山体边界没有因导出产生模糊。

导出后不要立即删除PSD或旧版BMP。

## 12. 常见错误

### 使用普通画笔

后果：

- 产生半透明边缘；
- 产生大量未登记RGB；
- 游戏可能报告未知省份颜色。

解决：

- 改用铅笔工具；
- 重新绘制受影响区域。

### 使用一个ID绘制多个不相连山体

后果：

- 同一省份出现多个连通块；
- 点击和审计困难；
- 后续修改容易误伤。

解决：

- 为不相连山体分配不同ID和RGB。

### 只靠对角线连接

后果：

- 四向连通检查失败；
- 省份可能在引擎中表现异常。

解决：

- 增加至少一条上下或左右连接。

### 山口只剩一个像素

后果：

- 后续一笔修改就可能封死道路；
- 邻接极不稳定。

解决：

- 保留多条连续公共边。

### 忘记显示图层

后果：

- PSD中能看到山体，但导出的BMP缺少其中一段。

解决：

- 导出前检查每个山体图层的眼睛图标。

### 直接覆盖基线

后果：

- 失去可靠回退版本。

解决：

- 分别保存基线、PSD和版本化BMP。

### 导出成32位或索引色

后果：

- 文件格式可能不符合项目要求；
- EU4可能无法正确读取。

解决：

- 使用Windows、24位、无压缩BMP重新导出。
