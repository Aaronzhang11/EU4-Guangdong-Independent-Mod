- **适用版本**：以 EU4 1.37.* 的脚本能力为设计边界
- **关联文档**：[设计支柱](00_design_principles.md)、[周盟系统技术架构](03_zhou_system_architecture.md)、[诸夏文化与思想变局](../world/05_culture_and_ideologies.md)

## 一、核心结论

本系统采用以下基本关系：

> **礼教是共同接口和秩序框架，百家是对它的不同具体实现。**

礼教规定诸夏国家仍在共同讨论的基本问题，例如名分、盟誓、祭祀、治国责任与诸侯相处之道；儒、法、墨、道、兵、纵横等学派则分别回答国家应当如何治理自身、如何履行礼教，以及应当如何对待天下其他国家。

百家不能设计成花费金钱、点数或宗教资源直接购买的一组临时增益。国家必须先形成国论，再持续做这套国论所推崇的事情，通过“践履”获得相应效果。玩家获得的收益应当是长期行为的结果，而不是按钮本身的商品。

同样，百家不直接等于 EU4 的省份宗教。国家今天采用法家国论、以后改行儒家国论时，不应把所有省份重新传教一遍。

## 二、五层结构

| 层级 | 表现内容 | 建议状态载体 | 变化速度 |
|---|---|---|---|
| 礼教框架 | 诸夏共享的政治、礼仪与讨论语言 | 国家宗教／资格触发器 | 极慢 |
| 地方礼俗 | 省份长期形成的祭祀、宗族与信仰共同体 | 省份宗教 | 很慢 |
| 百家影响 | 学宫、墨社、法吏、道门、讲武与游士网络 | 少量省份修正和事件 | 中速 |
| 本国国论 | 朝廷当前采用的治国路线 | 国家旗标、变量和国家修正 | 中速，有更张限制 |
| 天下显学 | 当前周天下认可的国际行为准则 | 周国锚点上的互斥旗标 | 定期由天下大辩改变 |

辅助数值继续沿用以下分工：

- **践履**：本国是否真的按照当前国论办事，建议范围为 `0—100`；
- **盟功**：本国在周天下的贡献与话语权，建议范围为 `0—100`；
- **礼乐值**：整个周天下秩序的有效程度，沿用现有周盟系统；
- **学主**：某届天下显学的主要提出国或实践典范，不是能够号令各国的宗教领袖。

## 三、省份宗教不等于百家

### 3.1 省份宗教表现什么

省份宗教应当表现比朝廷国论更稳定的地方社会结构，包括当地祭祀传统、宗族礼俗、寺院网络以及真正具有排他性的信仰共同体。

首版推荐采用最保守的实现：

- 诸夏腹地继续使用一个稳定的礼教容器；当前显示层暂时沿用现有 `confucianism`，最终机制是否新建宗教键另行审计；
- 佛教、印度教、东正教及其他真正独立的宗教继续使用原生宗教系统；
- 暂不为了表现儒、法、墨、道而批量改写全图省份宗教；
- 地方礼俗是否进一步拆为齐鲁、荆楚、吴越、巴蜀和百越等类型，留到后续版本决定。

只有当地信仰与社会组织真的发生长期改变时，才应使用原版宗教转换。例如佛教或印度教长期传播、大规模移民改变地方社会、当地祭祀体系被另一套宗教组织替代等。

### 3.2 百家在省份中的表现

百家允许同时存在，因此不使用只能容纳一个值的省份宗教槽。首版已以十二座具名学宫
承载六家省份存在：每家两座，每座使用固定非地理专名和唯一永久省份修正。
学宫始终提供地方教育收益；与主学派一致时提供一份不叠加的国家协同；既非主学派、
也未受受邀第二学派保护时，则按不同异派种类产生封顶的思想张力。

异派学宫可以被容忍，也可遭受三年逐学。逐学到期后，学宫在同派、受邀同派或友好礼教
国家中寻找庇护并迁往合格城市；故地留下遗址，无人接纳时则流散，等待天子年度脉冲的
低频复兴。这些变化移动具名省份修正，不改写省份宗教。

首版不追踪每个省份六家各自的精确数值，也不进行每月全图循环。完整名册、数值、
权威状态和同步边界见[具名学宫：省份思想载体与国家协同](07_named_academies.md)。

### 3.3 国论更张时的地方反应

国家改变国论时：

1. 省份宗教保持不变；
2. 新国论的践履降低或重新开始积累；
3. 旧国论留下有期限的“旧制余绪”；
4. 已实装的具名学宫协同与异派张力立即刷新；
5. 学派据点影响推行速度与“政令更张”地方事件属于后续扩展。

这表现的是政策、官僚和知识网络的重组，而不是宗教人口在一夜之间改宗。

## 四、本国国论与践履

### 4.1 形成国论

无主学派的礼教国家通过“召集诸子百家”形成第一套国论。“诸子临朝”分成两页，
依次列出儒、法、墨与道、兵、纵横六家；每家都有独立确认卡，暂缓则两年后再议。
首次立论从 `25` 点践履开始，并获得十年更张冷却。已有主学派的国家不能重走这条
免费入口，只能使用下文的长期国论更张。

为了控制事件量和组合爆炸，首版只实现六个固定主学派；两家合流国论仍是人工设计的
后续扩展，不生成任意两家的全部排列组合，也不保留“重申同派换取践履”的按钮。

### 4.2 践履而非购买

国论本身不立即提供完整收益。国家只有持续完成对应行为，才能提高践履并进入更高效果档位。

| 践履区间 | 工作称呼 | 效果原则 |
|---:|---|---|
| `0—24` | 名实未副 | 不再使用通用轻罚；承受与本学派承诺直接相反的专属重罚 |
| `25—49` | 试行 | 获得第一档效果 |
| `50—74` | 笃行 | 获得第二档效果 |
| `75—100` | 成法 | 获得完整效果，但违反本家原则时损失更明显 |

`0—24` 的专属反噬如下；这些修正彼此不叠加，每个国家只承受当前国论对应的一组：

| 学派 | 低践履状态 | `0—24` 实装反噬 |
|---|---|---|
| 儒 | 礼崩名乱 | 全国叛乱度 `+2`；提升稳定度花费 `+15%`；外交声誉 `-1` |
| 法 | 法令不行 | 月度自治度变化 `+0.10`；造核花费 `+10%`；年度腐败 `+0.10` |
| 墨 | 守义不修 | 要塞维护费 `+25%`；要塞防御 `-20%`；发展成本 `+10%` |
| 道 | 失道扰民 | 全国叛乱度 `+2`；月度厌战 `+0.03`；发展成本 `+10%` |
| 兵 | 武备弛废 | 人力恢复速度 `-20%`；陆军传统衰减 `+1%`；陆军士气 `-10%` |
| 纵横 | 信义俱失 | 改善关系 `-25%`；外交声誉 `-1`；外交关系 `-1` |

首次立论仍从 `25` 点开始，不会刚采用就吃反噬；主动改换国论从 `15` 点开始，因此
必须承担一段明确的制度阵痛。若日后因行为背离本家原则跌回 `25` 以下，也会立即由
正面档位切换为对应反噬，直到重新达到 `25`。

建议首批学派与行为方向如下，具体数值必须通过原型平衡：

| 学派 | 提高践履的典型行为 | 违背国论的典型行为 |
|---|---|---|
| 儒 | 履行盟约、维持安定、复国、以调停解决诸侯争端 | 背盟、绝人社稷、长期无名战争 |
| 法 | 降低自治、执行成约、维持稳定行政与统一法令 | 频繁特赦又反复改令、长期行政失控 |
| 墨 | 援助防御战争、修复荒废、保护小国与城邑 | 主动兼并、造成高荒废、拒绝救守 |
| 道 | 保持和平、降低厌战与荒废、减少过度征发 | 连续扩张、长期高厌战和强制干预 |
| 兵 | 训练军队、承担边防、赢得对外战争和共同防御 | 拒绝防务、长期军备废弛、无准备而败 |
| 纵横 | 维持盟友、保证独立、调停、组织外交阵线 | 频繁背盟、出卖盟友、外交信誉崩溃 |

这些行为应优先使用可靠的原生状态、战争结果和低频事件检查。无法稳定侦测的细节不作为核心计分条件。

### 4.3 当前六家国内原型

当前原型将国论保存在六个互斥国家旗标中，将践履保存在国家变量
`zhx_doctrine_practice` 中。首次立论统一使用六家两页目录，不扣除金钱、君主点数
或宗教资源；后续换派则必须具备第二学派或具名学宫根基并经历完整改革周期。

- 首次形成国论时，践履从 `25` 开始；
- 后续正式更张时，践履重置为 `15`；
- 首次采用后十年内不得发动更张；不提供重申当前国论的践履奖励；
- 首次议论暂缓时冷却两年；
- 年度结算一次践履，随后钳制在 `0—100` 并刷新当前效果档位；
- 年度结算跨过 `25`、`50` 或 `75` 时，只向玩家弹出一次升档／降档回执；AI 与未跨档年份不弹窗；
- 周天下内的玩家年度结算跨过 `70` 时，另显示一次获得／失去天下请辩践履门槛的短回执；
- 离开礼教后，国论旗标、践履、年度变化、档位修正与更张冷却会由
  `on_religion_change` 立即清理；年度检查只保留为低频安全网；
- 省份宗教在全部过程中保持不变。

首版年度行为公式如下。这些数值是用于实机验证的可调参数，不是永久平衡承诺。

| 学派 | 年度正向践履 | 年度负向践履 |
|---|---|---|
| 儒 | 稳定度至少 `1`：`+2`；威望至少 `25`：`+1`；厌战低于 `3`：`+1` | 负稳定度：`-3`；威望低于 `-25`：`-1`；厌战至少 `5`：`-2` |
| 法 | 腐败低于 `2`：`+2`；平均超最低自治低于 `25`：`+1`；过度扩张低于 `10%`：`+1` | 腐败至少 `5`：`-3`；平均超最低自治至少 `50`：`-2`；过度扩张至少 `25%`：`-2` |
| 墨 | 作为防御方战争领袖：`+3`，否则和平：`+2`；无借款：`+1`；厌战低于 `3`：`+1` | 作为进攻方战争领袖：`-4`；至少三笔借款：`-2`；厌战至少 `5`：`-2` |
| 道 | 和平：`+2`；厌战低于 `2`：`+1`；过度扩张低于 `5%`：`+1` | 厌战至少 `5`：`-2`；过度扩张至少 `25%`：`-2` |
| 兵 | 陆军达到上限 `80%`：`+2`；陆军传统至少 `40`：`+1`；人力至少 `50%`：`+1` | 陆军低于上限 `50%`：`-2`；陆军传统低于 `20`：`-2`；人力低于 `15%`：`-2` |
| 纵横 | 至少两个盟友：`+2`；外交声誉至少 `1`：`+1`；威望至少 `25`：`+1` | 没有盟友：`-3`；外交声誉低于 `0`：`-2`；威望低于 `-25`：`-1` |

当前尚未制作独立的专属学宫页；国家宗教页已提供学派徽章、国论、践履和效果档位。
六家原生徽章悬停使用统一短卡：顶部两句分别交代真实思想源流与本世界线周天下沿革，
下部用红、黄、绿、橙列出四个专属境界及该范围实际生效的完整修正。此卡是静态学派
说明，因此本国宗教页与外国外交页可共用同一文本，不动态读取当前档。两处原生徽章
本来只显示学派名，现由同尺寸透明悬停层接管提示，不会重复绘制或改变图标。宗教地图
的逐国图标没有受支持的自定义 GUI 根，仍保留引擎原生的名称提示。

践履数字继续使用红、黄、绿、橙四档颜色；悬停只显示按本月国情已经触发的因素，
每项独占一行，正项在前、负项在后，行末增减值统一以蓝色强调。
顶部“按本月国情触发合计”是这些行的原始总和；没有触发因素时会明确说明，而不会
留下空白提示。显示缓存只由人类玩家的礼教国在月度 pulse 中刷新本国一次，AI 无
宗教页读者，因此不做无意义月刷；整个过程不遍历其他国家或省份。整个 `28×24`
践履数字槽都是无框点击区，悬停末行提示玩家点击；点击打开完整践履准则、当前践履、
距下一档和距 `70` 点请辩门槛。礼鼎不承载规则事件，只作为鼠标穿透的礼教美术
覆盖；底下的原生请士按钮承载已经实装的“延请异派学者”机制。

悬停合计为了让逐行数字可以直接相加，不显示 `0—100` 上下限造成的截断；真实年度
结算仍会先钳制到 `0—100`，跨档回执也只报告实际获得或失去的点数。跨过 `70` 点时，
周天下玩家还会收到一张请辩门槛变动回执；域外礼教国与 AI 不弹。“查看国论与践履”
决议继续作为后备入口；常驻国家修正则表现 `0—24`、
`25—49`、`50—74`、`75—100` 四个效果档位。

若同一次结算既跨过 `70` 又跨过效果档位，请辩门槛回执优先，只显示一张事件；非
周天下礼教国不具备上书资格，因此仍按普通档位变化显示。这样不会在同一天堆叠两张
践履通知。

### 4.4 主学派更张闭环

国论不是可随时切换的姿态按钮。已有主学派的国家只能把受邀第二学派，或境内一座
未遭逐学的同派具名学宫，作为目标学派的国内根基。玩家从“更张国论”决议选择目标
并确认后，进入五年“广开新论”：全国叛乱度 `+1`、提升稳定度花费 `+15%`、顾问
花费 `+15%`。期间锁定新邀请且不能提出新的天下大辩请辩书；已经开始的天下投票仍
按旧主学派结算。若宾学是唯一根基，其剩余驻留时间必须覆盖完整五年培植期，并额外
保留一日引擎结算余量；仅剩精确五年时必须先续聘。培植期间始终至少要保留宾学或一座活跃同派具名学宫：宾学
期满、被逐客或失去效力时，境内仍有同派学宫则继续培植，否则改革立即失败；学宫
消失、迁走或进入逐学时也按同一规则复核。

五年到期且天下公议空闲时，国家失去 `1` 稳定度和 `25` 威望，新学成为主学派、践履
设为 `15`，旧学以无数值的第二徽章保留十年“旧学余势”，只保护同派学宫，不提供
主学派或受邀客学收益。若天下公议仍在进行，正式采用每三十日复核，直到公议结束；
换派后旧学请辩书立即清理，不改写已经投出的选票。其他旧学国家对本国获得十年衰减的
`-20`“背弃旧论”，新学国家获得十年衰减的 `+10`“同声相应”。若新学原为本国宾学，
正式扶正会静默收束其宾学契约，不视为提前逐客，也不触发礼送、失信或外交惩罚。

接下来的十年“新旧相攻”给予：全国叛乱度 `+2`、提升稳定度花费 `+25%`、治理容量
`-10%`、国家税收 `-10%`、人力恢复 `-10%`。到期按新学践履结算：

- 践履至少 `50` 且稳定度至少 `1`：十年“新政既定”，全国叛乱度 `-1`、提升稳定度
  花费 `-10%`、改革进度增长 `+15%`、顾问花费 `-10%`；
- 践履 `25—49`，或践履虽达 `50` 但稳定不足：结束争论但不给奖励；
- 践履低于 `25`：可以再失去 `1` 稳定度强推五年，或恢复旧学。

强推到期无论践履高低都结束，不授予“新政既定”，随后冷却十年。恢复旧学则把旧学
设回主学派并将践履设为 `25`，失败的新学以第二徽章保留十年；国家承受十年“朝令
夕改”（所有君主点花费 `+5%`、改革进度增长 `-25%`、外交声誉 `-1`、提升稳定度
花费 `+20%`），十五年内不得再次更张。中途主动撤议会造成五年“朝议无定”（提升
稳定度花费 `+10%`、外交声誉 `-1`）和十年冷却。

AI 仅在 `1475` 年以后、当前践履连续五年低于 `25`、和平、稳定至少 `1`、无灾难和

## 五、天下大辩与国外影响

### 5.1 国内国论与天下显学分离

本国国论回答“本国怎样治理”，天下显学回答“诸侯之间怎样相处才被视为正当”。天下大辩不会强迫所有成员采用胜出学派，也不会转换任何省份宗教。

一个采用法家国论的国家可以生活在墨家成为天下显学的时期。它可以对内继续行法、对外遵守非攻准则，也可以公开反对现行秩序并承担盟功与外交代价。

### 5.2 正式请辩与召开条件

践履达到 `70` 只代表一个国家有资格上书，不会把其国论自动塞进候选池。正式请辩还
必须同时满足以下社会基础：

- 该国是周天下内以礼教为国教的现存国家；
- 当前国论践履至少 `70`；
- 同一学派至少有三个周天下礼教国家采用；
- 除上书国之外，另有一个同派国家践履至少 `50`；
- 当前没有十五年天下显学任期，也没有正在进行的天下大辩。

儒、法、墨、道、兵、纵横六家的请辩书互相独立，每份有效 `1095` 天。只有一份请辩
时不会占用天下公议，也不会阻止其他学派继续上书；到期后自然失效，因此不存在单一
候选永久堵塞系统的问题。上书国灭亡、离开周天下、改宗、改换国论或践履跌破 `50`
时，天子的年度清理会撤销其请辩书。

至少两份请辩同时有效且天下公议空闲时，天子可以召开大辩：恰好两份时按固定学派
次序自动填入甲、乙两案；三份以上时先选择甲案，再从余下请辩中选择不同的乙案。
入席后所有本轮请辩书结案，正式进入为期一年的共享天下公议。

### 5.3 天下显学改变国际规范

天下显学不主要向所有成员发放同一个经济或军事增益，而是改变以下三类规则：

1. 哪些国际行为增加盟功与礼乐值；
2. 哪些行为受到更严重的谴责；
3. 周天下能够启动哪些调停、制裁或共同应对行动。

| 天下显学 | 受赞许的国际行为 | 受谴责的国际行为 | 可用的周天下行动方向 |
|---|---|---|---|
| 儒 | 履约、复国、归还故土、尊王救难 | 背盟、灭国、无名攻伐 | 正名、调停、复国之议 |
| 法 | 执行盟约裁决、按期履行共同义务 | 拒绝裁决、拖欠义务、破坏成约 | 申盟、制裁、合法讨伐 |
| 墨 | 援助被侵略国、救守、减少战争破坏 | 主动兼并、拒绝救援、造成高荒废 | 非攻之议、救守援助 |
| 道 | 长期和平、休养、减少干涉 | 频繁战争、强制改宗、过度征发 | 弭兵、休战倡议 |
| 兵 | 边疆防御、对外战争、承担共同军务 | 拒绝防务、临阵退缩 | 方伯统军、攘夷共战 |
| 纵横 | 结盟、保证、调停、组织共同阵线 | 反复背盟、出卖盟友 | 合纵、连横、临时会盟 |

第一版只需要让显学改变盟功、礼乐值和少量事件选项，不急于为每家制作独立外交按钮或战争系统。

### 5.4 大辩结果

天下大辩不保证产生唯一胜者。首版允许两种结果：

- **定于一尊**：一家成为限期显学，国际规则执行力较强，但其他学派抵触较大；
- **百家并立**：学者交流与思想创新更活跃，但周天下难以用单一学说制裁成员。

“百家并立”是正常且有价值的结果，不视为系统失败。其核心取舍是：思想越集中，国际规范越容易执行；思想越多元，学术交流越活跃，但共同制裁越困难。

### 5.5 学主与软实力

显学的主要提出国可以在本届成为“学主”：

- 更容易吸引或派遣相关学者；
- 与支持该学说的国家改善关系；
- 可通过少量事件传播学宫或顾问；
- 若公开违背本家原则，则触发更严重的“名实不副”。

首版只保存当前显学及其提出国，用事件表现请士和声望；不建立逐国逐学派的跨国传播网络。

### 5.6 当前成熟六家大辩

天下大辩与天下事变现在共用一套“天下公议”内核，但议题来源与结算规则不同：天下
事变处理一次性的秩序危机；天下大辩处理六家长期竞争形成的国际规范。两者共享甲、
乙、丙三档冻结选票、实时点票、改票、`365` 天期限和互斥忙碌状态，因此不会同时占用
面板或建立两套彼此打架的投票。

1. 六家通过独立请辩书进入候选流程，而不是由第一个到达 `70` 的国家自动提案；
2. 天子在两份请辩时直接开议，三份以上时以两步事件选定甲、乙两案；
3. 所有现存周天下国家分别支持甲案、乙案或“百家并立”；
4. 每国基础一票；践履达到 `75` 且所投恰为本国国论者，在投票时冻结一张实践典范
   加票，因此共计两票；以后践履变化不会追溯改写已投权重，主动改票会重新冻结；
5. 每次改票都刷新公开票数，结算时只清理已经灭亡或离开周天下的票；
6. 某一家必须同时严格领先另一家和“百家并立”才能成为显学；任何第一名并列都按
   “百家并立”结算，天子没有隐藏破平权；
7. 支持胜出显学的成员获得 `2` 盟功；“百家并立”胜出时，其支持者获得 `1` 盟功；
8. 结果由 `zhx_tianxia_orthodoxy_term` 固定 `5475` 天，即十五年；所有显学国际效果与
   新一轮请辩都以这一个任期修正为门控，任期结束后旗标会由年度安全网清理；
9. 显学只改变国际礼乐与盟功评价，各国国内国论、践履和省份宗教保持不变。

#### AI 投票怎样跑完一整届

候选确定后，系统先把甲、乙两案各自的上书国另存下来，再清掉已经结案的六家请辩书。
这一步很重要：请辩书可以消失，但“这案是谁提的”必须保留到投票结束，否则 AI 无法
根据盟友、好感、宿敌和战争关系判断该支持谁。

开票后的顺序如下：

1. 系统在同一个开票动作里遍历全部有资格的 AI 国家，先写入每国甲、乙、丙选票，再由
   天子统一点票一次；因此玩家看到投票事件和公议面板时，AI 首票已经全部落账；
2. 玩家国家随后收到投票事件，可以选择甲案、乙案或百家并立；
3. 第 `61` 天由天子统一检查一遍。只要某个后来加入、恢复存在或因异常没有甲乙丙选票
   的有资格 AI，就同步补投；
4. 第 `182—211` 天，每个已经投票的 AI 最多重新判断一次。半年内盟友、好感、宿敌或
   战争关系发生变化时，它可以改票，但不会每月反复横跳；
5. 第 `365` 天冻结前再补齐一次漏票，然后结算。过期的复议事件即使后来触发，也会因为
   公议已经关闭而失效。

AI 依照可解释的优先级投票：本国国论与候选学派相同最优先，其次支持本国提出的方案；
再看自己是否只与一方提案国结盟或保持至少 `50` 好感，或是否只与一方互为宿敌、正在
交战。友好关系把票推向该案，敌对关系把票推向另一案。本国已有国论但两案都未提名时，
优先支持百家并立；只有既无明确学派归属、也无单边外交倾向的国家才按甲 `40`、乙 `40`、
并立 `20` 随机选择。因此同派和友邦会抱团，敌国会回避对方提案，落选学派也有明确去向。

天子现在同时保存六个投票进度数：全部有资格国家、已投国家、未投国家，以及其中
有资格 AI、已投 AI、未投 AI。逐国选票仍保存在各国自己身上，但甲乙丙总票数和上述
进度数只允许明确写到 `event_target:zhx_tianzi`，周天下面板读取的也是这一份公共账。

此前调试时出现“只有玩家一票，其他都是零”，不是 AI 完全没有选择倾向，而是两层
问题叠在一起：延迟隐藏事件没有可靠地让各国完成首投；点票脚本又曾通过 `ROOT` 修改
公共票数，而 `ROOT` 不会因为外层进入天子作用域就自动变成天子。现在首票不再依赖
逐国延迟事件，而是在开票动作内同步完成；写票期间暂缓重复点票，所有 AI 写完后只在
天子公共账上重算一次。面板出现时应当已经是“全部合资格 AI 已投”，第 `61` 天与结算
前的检查只负责后来加入或异常漏票的国家。

开票时只预排第 `365` 天的隐藏期限事件。期限事件冻结最终票数、设置一次性的
`zhx_council_result_ready` 并进入“正在定论”，随后按本届议题种类延迟一天打开可见结果
窗口；这样绕开 EU4 会吞掉同步派发窗口的问题，又不会在开票时额外留下一个可能误撞
后届公议的陈旧结果定时器。结果窗口严格要求“正在定论＋本届议题种类＋结果已就绪”，
结案时三者一并清理；这一日不延长投议期，也不给任何国家追加改票时间。

“查看天下显学”报告保留国际准则正文，并提供按需计算的“查看六家名势”短页；短页
列出各家采用国总数和其中践履达到 `70` 的国家数。诸夏王会右侧常驻显示当前显学和
六家有效请辩状态；左侧只在公议进行中显示甲、乙候选、实时票盘、本国立场和改票按钮。

当前六家显学的国际规范如下：

| 结果 | 天下和平与诸侯内战 | 周天下国家击败域外战争领袖 |
|---|---|---|
| 儒 | 完全和平每年额外礼乐 `+1`；发生内战额外 `-1` | 礼乐 `+3`；成员胜方盟功 `+2` |
| 法 | 无内战每年额外礼乐 `+1`；三场以上内战额外 `-2` | 礼乐 `+5`；成员胜方盟功 `+3` |
| 墨 | 完全和平每年额外礼乐 `+2`；发生内战额外 `-2` | 礼乐仅 `+1`，不因胜利本身奖励盟功 |
| 道 | 完全和平每年额外礼乐 `+2`；发生内战额外 `-1` | 礼乐 `+1`；成员胜方盟功 `+1` |
| 兵 | 无内战每年额外礼乐 `+1`；三场以上内战额外 `-1` | 礼乐 `+5`；成员胜方盟功 `+4` |
| 纵横 | 无内战每年额外礼乐 `+1`；三场以上内战额外 `-1` | 礼乐 `+3`；成员胜方盟功 `+2` |

甲、乙、丙票盘时按需列出支持国及其冻结票权；正式请辩决议与“查看天下显学”决议保留
为 GUI 失效时的后备入口。

## 六、与现有系统的边界

### 6.1 周天下面板

周天下负责国际层：

- 天下大辩的召开与候选；
- 成员表态和结算；
- 当前天下显学、学主及剩余任期；
- 显学对盟功、礼乐值和天下事变的影响。

### 6.2 国内学宫

宗教页与省份学宫共同负责国内层：

- 当前受邀学派；
- “诸子临朝”首次立论与主学派更张；
- 当前国论；
- 践履及其来源；
- 国论更张与旧学余势。
- 具名学宫在省份上的地方收益、主学派协同与异派思想张力。
- 异派学宫的容忍、逐学、撤令、跨国庇护、迁徙、遗址与流散复兴。

本阶段不另做学宫页面；玩家从省份修正和国家修正查看学宫结果。周天下面板不保存
学宫驻地，也不负责逐学与迁徙。

### 6.3 原版天命复用界面

原版天命界面继续负责其持有者的改革、圣旨和国内制度，不负责周天下成员名册，也不成为天下大辩或各国国论的状态真源。

三者只通过少量明确接口互相影响。例如高践履使国论有资格参加天下大辩，天下显学改变盟功结算，但国际结果不能直接覆盖本国国论。

## 七、技术实现建议

以下名称均为工作名，正式编码前仍需统一审计。

### 7.1 国家状态

- 一组互斥主学派旗标与 `0—100` 践履变量；
- 更张目标、旧学、启动根基及培植／过渡／强推阶段旗标；
- “广开新论”“新旧相攻”“新政既定”“朝令夕改”“朝议无定”及独立冷却修正；
- 受邀第二学派修正，以及无数值的旧学余势第二槽标记；
- “名实不副”状态及其清理条件。

### 7.2 周国锚点状态

- 一组互斥的天下显学旗标；
- 当前学主的全局事件目标；
- 本届大辩阶段、候选和任期变量；
- “百家并立”作为独立结果旗标，而不是无显学时的错误状态。

### 7.3 更新频率

- 战争、结盟、背盟等有可靠 on-action 的行为即时结算；
- 和平、荒废、厌战和行政状态通过年度或半年脉冲汇总结算；
- 践履和盟功写入后统一钳制范围；
- 不使用每日检查，不对全图省份进行每月多维学派扫描；
- 界面只读权威状态并调用小型效果，不承担模拟循环。

### 7.4 原生风格的宗派呈现外壳

首版在国家宗教页沿用原生学派名称与专属徽章，并在同一行紧凑显示践履数值；外国
外交页显示当前学派徽章；宗教地图模式则在各国首都显示一枚学派徽章。省份宗教仍
保持礼教，不因国论更张发生批量改宗。

这里复用原版 `religious_school` 作为**只读显示镜像**，但不把它当作玩法真值：

- `zhx_doctrine_ru/fa/mo/...` 国论旗标和践履变量仍是唯一权威状态；
- 隐藏事件 `zhx_doctrine.91` 把六家旗标同步为 eastern 宗教组的原生宗派，仅供宗教页、
  外交页和宗教地图读取；字面量 `set_religious_school` 必须直接留在该事件中，避免
  EU4 1.37.5 对深层 scripted effect 未完成后校验而产生 `Invalid school in scope`；
- 隐藏事件 `zhx_doctrine.92` 接入 `on_religion_change`：离开礼教时先清除所有国论玩法
  状态；若改宗后的国家仍属于 eastern 宗教组，则以透明的“未立国论”哨兵替换旧
  原生宗派，避免外交页和宗教地图继续显示旧学派；跨宗教组时不强写 eastern 学派，
  以免产生 `Not same group`；以后回到礼教且没有国论时，会再把仍存的旧指针替换为
  哨兵，因此不会复活原国论；
- 六个镜像宗派本身没有永久数值修正，只为已有国论的礼教国承担显示与异派延请路由；
  候选、确认和执行三层均按权威国论旗标校验，佛教、神道等同组宗教不能借此获得百家
  修正；
- 六家均已接入统一的“诸子临朝”首次采纳、年度践履与四档效果。已有主学派只能以
  受邀异派或同派具名学宫为根基，经过五年培植、正式采用、十年过渡及结局结算完成
  更张；不再存在“重申现论加 `5`”或两组“邀请两家—辩论—立论”入口；
- 宗教页不再另放一张国论大卡：践履数值固定在原生学派名称和请士按钮之间的
  `28×24` 空位，四档使用互斥的红、黄、绿、橙数字。数字上方叠加同尺寸的全透明
  点击层；悬停只列本月已触发项，正项在前、负项在后，每行数值为蓝色，零触发有
  明确空状态，末行提示点击查看完整准则；
  该位置位于宗教守护者上方，也不侵入下方的未统一省份与传教士列表；
- 礼教宗教页以鼠标穿透的礼鼎覆盖原生请士按钮中的伊斯兰月牙，底层按钮、学派列表
  与后续选择流程仍归引擎所有；“未立国论”哨兵使用不带学派标志的中性礼制圆环。
  两者条件互斥；非礼教东方国家使用同尺寸、无状态的背景补片还原底板和金色分隔线，
  并将左端卷轴头镜像为对称右端、截获组级按钮，视觉上不留下圆环、月牙、平切端或
  矩形接缝；伊斯兰国家仍使用原生界面；
- 六家原生宗派说明各含两句短史和四行档位卡：真实思想源流一句、周天下延续至
  `1444` 年的制度地位一句，随后保留学派专属档位名并显示该档完整效果。共享说明不
  动态高亮当前档，避免外交页作用域错读；宗教页和外交页分别以 `26×26` 透明层覆盖
  原生名称提示，宗教地图则因无受支持的逐国自定义悬停根而继续只显示学派名；
- 外交页以所需的中文本体 1.37 GUI 为基线机械生成，国名与副标题右移并收窄，给
  52 px、`0.5` 倍缩放的宗派徽章留出 6 px 间距；
- 原生宗教地图只在国家首都绘制宗派徽章，并使用低优先级碰撞消隐；军队密集或视野
  很远时，局部徽章可能暂时让位，这是原版行为；
- 原生外交与地图宗派徽章需要《文明的摇篮》DLC；没有该 DLC 时，宗教页紧凑践履
  数值、决议和国家修正仍能呈现玩法状态。

原生宗派槽没有脚本化的 `clear_religious_school`。透明哨兵因此仍被引擎视为“有宗派”：
它可能占用一个低优先级地图图标碰撞位，同为哨兵的国家也可能触发原版“同宗派”关系
修正。首版接受这一原生接口成本，不会为消除此副作用而全局改写伊斯兰学派关系规则。
若以后该成本影响实际平衡，应放弃原生地图徽章镜像，而不是继续堆叠隐藏兼容层。

本项目在宗教原型阶段默认以新开局为准：版本迭代不承诺修复开发期旧存档，也不在
`on_startup` 注入迁移事件。只有正常游玩中必然发生的首次采纳、延请、主学派更张、
学宫刷新、年度同步和改宗清理生命周期属于正式兼容边界。

地图模式快捷键取决于玩家自己的主地图槽位。本次实机环境中宗教地图位于第 5 槽，
对应 `T` 而非 `R`；验收应点击宗教地图按钮或使用当前槽位的实际快捷键，不能把灰色
的帝国地图误认成宗教地图。

## 八、首版必须做与暂缓内容

### 8.1 最小可玩竖切

首版国内与国际竖切的第 `1—11` 项均已形成脚本闭环，成熟大辩和学宫生命周期的本轮
实机验收状态以
对应提交说明为准：

1. 诸夏省份宗教保持稳定，国论更换不触发传教；
2. 儒、法、墨、道、兵、纵横六个代表学派；
3. 一套六家两页“诸子临朝—逐家确认—初立国论”的事件链；
4. `0—100` 践履及四个效果档位；
5. 每家三到五个可靠行为来源和一到两个违背条件；
6. 以受邀异派或具名学宫为根基，包含五年培植、十年过渡、多结局及独立冷却的主学派更张闭环；
7. 六家请辩中选出两个提案，并带有“百家并立”的天下大辩；
8. 天下显学只先影响盟功、礼乐值及少量事件选项；
9. 决议、事件和修正仍是后备入口；诸夏王会左侧显示当前公议，右侧显示显学和六家请辩。
10. 十二座具名学宫、地方收益、主学派协同与封顶思想张力；
11. 容忍、三年逐学、撤令、外交反应、庇护迁徙、遗址、流散复兴与谨慎 AI 逐学。

### 8.2 原型稳定后扩展

- 加入农、名、阴阳、医等次级学派，并决定其出现时代与国家条件；
- 增加少量人工设计的两家合流国论；
- 每家至多增加一座条件严格的动态新宫；
- 机制成熟后再评估是否需要独立学宫页；
- 追加剧情型联合学宫、学术流亡与合流事件；
- 评估强迫停止逐学的低战分和平条款与流散学统总览；
- 让更多天下事变读取当前显学。

### 8.3 暂不采用或直接废弃

- 把儒、法、墨、道、兵、纵横制作成互斥省份宗教；
- 国家更换国论时批量转换省份宗教；
- 花费金钱、君主点数或单一宗教资源直接购买完整学派增益；
- 为每个省份保存所有学派的精确强度；
- 每日或每月扫描全世界全部省份和国家；
- 自动生成任意两家学派的全部组合；
- 让天下显学强制改变成员国国论或省份宗教；
- 首版制作高度动态的候选列表、投票名册和独立外交动作；
- 为了界面效果把模拟状态保存在 GUI 内。

## 九、验收标准

国内原型当前以以下标准验收：

- 更换国论后没有任何省份被自动改宗；
- 同一宗教的两个国家可以拥有不同国论与践履；
- 玩家无法只靠一次付款立即获得完整增益；
- 践履能够因可解释的游戏行为上升和下降，并在存读档后保持；
- AI能够形成国论并积累最低限度的践履，不会频繁改弦更张；
- 离开礼教会立即清除国论、践履、年度变化、档位和冷却；回到礼教时不会复活旧国论；
- 未立国论者只能确认六家之一或暂缓两年；已有国论者不能重走免费入口、重申本派或
  绕过更张状态机；
- 没有每日全图扫描造成的明显性能问题；
- 宗教页原生学派名称、徽章与紧凑践履数值能够正确区分六家；徽章悬停在宗教页和
  外交页显示同一份两句短史与四档完整效果，宗教地图保留原生学派名。践履数字按四档着色，悬停只
  显示本月已触发因素，正项先于负项且每行增减值为蓝色，逐行之和必须等于顶部原始
  合计；点击数字可以打开完整准则。礼鼎不得截获底层原生请士按钮，也不得与数字或
  宗教守护者重叠；
  若界面覆盖失效，仍能通过事件、决议和国家修正理解系统。
- 年度践履只有跨越档位边界时才向玩家显示一次回执，升档与降档均能正确显示，AI、
  同档变化和 `0／100` 封顶触底不得造成重复弹窗或错误变化值；
- 周天下玩家跨越 `70` 点时能收到请辩门槛得失提示；AI、域外礼教国和未跨线年份不得
  收到该提示；
- 同年同时跨越 `70` 与效果档位时只显示请辩门槛回执，不得连续堆叠两张通知；

国际原型还必须通过以下实机验收：天下显学改变和平、内战与域外胜利的盟功或礼乐
结算；法家国家可以在墨家显学下继续保持法家国论；国际“百家并立”能够正常结算、
结束任期并存读档。

同时确认宗教页学派名称、徽章与践履同步切换，宗教守护者和未统一省份列表不被遮挡；
查看外国时确认外交页徽章与国名不重叠；进入真正的宗教地图后确认首都徽章与国论同步。
每轮检查加载日志中不得新增 `Invalid school in scope`、缺失纹理或本系统 GUI 解析错误。

### 9.1 维护中的开发预览入口

正式模组保留一个永不被 `on_action` 或普通 GUI 自动调用的开发者预览事件，可从控制台
或存档级调试目录手动打开：

```txt
event zhx_debug.100 CZH
```

第一项生成墨家、道家两份请辩并直接开票；第二项生成儒家、兵家、纵横家三份请辩，
用于验证天子的两步择案。两项都调用正式的请辩、开票、实时改票、期限与结算状态机，
没有复制第二套玩法逻辑。预览会清除当前显学任期，因此只能在临时存档使用。

开发预览不能中止已经开票的公议。EU4 无法撤销已经排入队列的第 `365` 天期限事件；
强行复位会让旧期限误撞以后新开的公议。应让本届正常结算，或在三家择案阶段选择
“暂缓择案”，随后输入：

```txt
event zhx_debug.199 CZH
```

该命令只在公议空闲时清除预览标记、请辩、候选、显学任期和公议残余状态。它不会
还原结算已经产生的礼乐值或列国盟功，因此预览存档不应继续作为正式游玩档。

此外保留一个存档级开发者目录启用器：

```txt
event zhx_debug.1
```

确认后，本国决议栏会出现“调试”；点开后可在“天下公议”和“礼教学派”两页之间
翻页，并从“调试天下大辩”进入上面的 `zhx_debug.100`。每页最多六个选项，关闭普通
目录不会停用决议；第二页的“关闭并停用‘调试’决议”会清除本国启用旗标。

EU4 `1.37.5` 的控制台 `debug_mode` 是硬编码界面开关，没有对应的脚本触发器；
`is_debug = yes` 和 `debug_mode = yes` 都会产生 `Unknown trigger type`。所以模组无法
诚实地让原生 `debug_mode` 单独控制决议可见性，必须用上面的控制台事件设置存档旗标。
正常游戏没有任何 `on_action`、GUI 或普通决议会调用该启用器。

临时 `zhxtest` 事件、启动注入、直接学校探针及断言日志不得进入正式模组；静态校验器
会扫描整个生产模组并拒绝 `zhxtest`、`fatest`、`motest` 等测试夹具。开发期旧存档不在
本阶段验收范围内。
