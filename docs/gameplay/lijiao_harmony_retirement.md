# 礼教原版和谐机制退役契约

## 1. 文档定位

- **目标版本**：EU4 `1.37.x`，以当前模组和实际加载环境为准。
- **存档边界**：只保证全新战役；不迁移开发期旧存档中的和谐值、调和进度或已调和宗教列表。
- **核心原则**：原版和谐不再是玩法状态，也不作为礼教机制的隐藏兼容真值。

礼教的权威状态保持不变：六家互斥国论旗标保存主学派，
`zhx_doctrine_practice` 保存 `0—100` 践履，具名学宫省份修正保存学宫所在地，
宾学契约保存受邀第二学派；思想张力只由未受保护的异派学宫种类派生。

## 2. 退役范围

礼教国家不再拥有以下原版玩法：

- 连续 `0—100` 和谐值及高、低和谐国家效果；
- 选择外部宗教进行调和、调和进度和调和速度；
- 已调和宗教列表、按已调和宗教获得的修正和相关 AI 行为；
- 以和谐度支付议会贿赂，或通过事件、改革、理念被动增减和谐；
- 以原版和谐、调和数量或已调和某宗教作为任务、事件和改革条件。

正式实现应移除礼教宗教定义中的 `uses_harmony = yes`，并清理或改写可达内容中的
`harmony`、`add_harmony`、`has_harmonized_with`、`add_harmonized_religion`、
`num_of_harmonized`、`is_harmonizing_with`、`harmonization_progress`、
`add_harmonization_progress`、`yearly_harmony` 与 `harmonization_speed`。

原版和谐事件不能只依赖失效效果自然沉默。凡仍以 `religion = confucianism` 为触发条件、
能够正常弹出的事件，必须明确停用或按六家语义重写；继承的任务文件也必须替换旧门槛，
避免出现永远无法完成的任务。

## 3. 原和谐门槛的派生替代

旧门槛统一改为只读 scripted trigger。它们不得设置新旗标、变量或修正，只读取践履与
现有思想张力修正：

| 派生接口 | 等价条件 |
|---|---|
| `zhx_lijiao_cohesion_75` | 践履至少 `50`，且不是高张力 |
| `zhx_lijiao_cohesion_80` | 践履至少 `50`，且张力为无或低 |
| `zhx_lijiao_cohesion_90` | 践履至少 `75`，且张力为无或低 |
| `zhx_lijiao_cohesion_100` | 践履至少 `75`，且无张力 |

四个条件必须严格单调：满足更高条件时必然满足所有较低条件。这里刻意复用玩家可见的
践履 `50／75` 档和思想张力四档，不引入不可见的“践履80／90”次级门槛。

思想张力的读取以现有互斥国家修正为准：无修正即“无”，
`zhx_academy_tension_mild` 为“低”，`zhx_academy_tension_medium` 为“中”，
`zhx_academy_tension_heavy` 为“高”。这些修正仍是可重建的派生显示与效果状态；
具名学宫的省份修正才是最终学宫真值。

## 4. 外教容忍不等于百家共存

`has_harmonized_with = X` 没有学派层的一对一替代。佛教、景教、伊斯兰教等是省份和国家
宗教；儒、法、墨、道、兵、纵横是礼教内部国论。不得用下列状态冒充“已调和外教”：

- 宾学契约或受邀第二学派；
- 具名学宫、学宫保护或思想张力；
- 原生 `religious_school` 显示镜像；
- 新增 `zhx_harmonized_*` 永久国家旗标。

旧内容若表达现实共存，应按语境读取原生当前状态，例如异教／异端容忍、宗教统一、
本国宗教、原生第二宗教、盟友关系、对应宗教省份及当地叛乱。旧条件若只是已有容忍分支
的重复入口，可以直接删除。`add_harmonized_religion` 开局历史和事件效果不迁移为任何
百家状态；`num_of_harmonized` 任务应改写为宗教统一、社会安定与上述 cohesion 条件。

## 5. 旧数值效果的处理原则

- `add_harmony = ±N` 不能机械全局替换。只有事件确实表示履行或背离**当前国论**时，
  才可按 `1:1` 改为践履 `±N`，并调用共享的钳制、档位和账簿刷新接口。
- 原版禁书、官僚和礼俗事件并不对六家中立；首版应停用，后续如保留则逐学派重写。
- `yearly_harmony` 不改成无条件年度践履。践履必须来自明确行为；值得保留的制度奖励应
  成为年度践履悬停中可解释的一项条件。
- `harmonization_speed` 不映射到宾学二十年契约、五年国论培植或十年过渡期。旧来源若
  因此过弱，可另行给予普通数值补偿，但不能创建新的宗教进度。
- 原版“支付和谐度”议会贿赂直接失效；践履不是可消费货币。

## 6. 允许保留的失活原生残余

退役不要求为了清除无害文本而整文件覆盖所有原版通用定义。只要礼教已不再
`uses_harmony`，且没有可达脚本重新写入调和状态，以下残余可以保留：

- 原版宗教或宗教组中的 `harmonized_modifier` 元数据；
- 原版通用 static modifier、理念、奇观或改革中面向“使用和谐宗教”的
  `yearly_harmony`、`harmonization_speed` 定义；
- 引擎硬编码的 `current_harmony`、`harmonization_progress` 等 GUI 控件名；
- 被思想张力展示复用的原版和谐横条、底板、边框、游标、端点贴图和生成器基线名称。

这些内容只能是不可达的通用定义或纯美术骨架，不能继续改变礼教国家、解锁任务、触发
事件或显示为玩家可获得的有效奖励。模组自己直接提供的改革、法令和历史文件应优先删掉
误导性的旧效果；不应仅为删除原版全局失活定义而引入大规模脆弱覆盖。

## 7. 全新战役政策

- 新开局的礼教国家不得带有已调和宗教或调和中状态。
- 首次立论、国论更张、宾学和学宫生命周期继续使用现有初始化与刷新入口。
- `1444` 自建国若以合资格文化和礼教开局，会在次日进入六家立论；非合资格自建国不能以
  没有主学派的空壳礼教绕过资格门。
- 新释放国家会立即经过同一资格与立论入口；其他事件建国若合法采用礼教但没有主学派，
  年度安全网会在两年“暂缓立论”修正结束后补发一次，不会逐月扫描或堆叠弹窗。
- 改宗和主流文化变化都会重新判定礼教资格；非诸夏国家若被原生和平条约或附庸互动强制
  改为礼教，会立即恢复其首都宗教，不生成没有主学派的“空壳礼教”。
- 不读取旧存档的和谐值来补造践履、学派、宾学或思想张力。
- 不为旧存档残留增加月度清扫、迁移旗标或第二套兼容状态。
- 若玩家加载退役前存档，结果不属于当前支持范围；验收一律使用全新 `1444.11.11` 战役。

## 9. 当前实装（2026-08-29）

本轮已经完成首版退役：

- `build_zhx_religions.py` 从固定的 EU4 1.37.5 宗教基线移除礼教的
  `uses_harmony = yes`，因此引擎不再为礼教创建可玩的和谐状态机；
- `build_zhx_harmony_retirement.py` 以 SHA 固定十五个原版文件，封存旧和谐事件，阻止日本、
  满洲、草原任务、儒教叛军和通用宗教事件让非诸夏国家改信礼教，并把七套继承任务改为
  cohesion／宗教统一／按实际省份宗教计算的容忍条件；同时停用神道改信礼教的废决议
  入口，并移除教士行动仍会实际写入的和谐／调和进度；
- `zhx_lijiao_cohesion_75／80／90／100` 已按第 3 节表格实装；
- 模组正式脚本、开局历史和宗教地理清单已经移除所有旧和谐读写；只有满足诸夏文化白名单
  （另含箕子朝鲜特例）的国家可采用礼教。因氐羌、蜀、陇文化标签仍覆盖若干非诸夏政权，
  巴氐、白马弥药、宕昌、邓至、贵阳、甘州、河州回回另列硬排除；壮族长生国开局宗教也已
  从错误的礼教纠正为泛灵论。改入礼教的通用路径会清理旧镜像，并在次日进入六家立论；
  离开礼教后即使绕经非东方宗教再改入佛教，也会清除残留的六家原生徽章；
- 改宗与主流文化变化共用同一个资格生命周期；强迫非诸夏国家改信礼教时，事件会恢复首都
  宗教（若首都本身也已礼教化，则使用万不得已的泛灵论回退），年度路径再提供一次安全网；
- 宗教页仍保留引擎所需的失活控件名和复用美术，但正式显示只读取践履及思想张力；
- `validate_zhx_harmony_retirement.py` 会重建并逐字比较固定覆盖，检查正式玩法脚本的
  花括号及旧 API，验证四档 cohesion、十二个失活事件编号、改宗边界和全新战役数据源。

也不能成为任务、事件、历史或模组数值奖励的有效接口。实机清单在取得全新战役证据前仍
保持未勾选，静态通过不冒充运行时验收。
