# 广东与粤国设计

## 文档定位

本文说明现有广东模组资产如何迁入《列国奉周》（工作名）世界线，并定义粤国在1444年开局、周盟政治和海外扩张中的玩法定位。

文中“已经存在”只表示当前仓库中已有对应文件，不表示已经在新世界线下完成兼容或实机验证。

## 状态摘要

### 已定设定

- 保留 `GDD` 作为广东／粤国的基础标签。
- 保留广州贸易特性、南海神庙资产、广东国家理念和梁氏人物作为迁移基础。
- 广东属于周盟的岭南诸侯，不再以“从明朝独立”为主要历史背景。
- 广东是诸夏开海、海疆备援和海外分封的重要参与者。

### 推荐方案

- 国家常用名为“粤”，周室正式封号为“粤公国”或“粤国”。
- 梁守谦在国内自称“岭南王”，但周室只承认其较低封号，由此制造合法性矛盾。
- 闽控制潮州，粤拥有潮州核心或历史宣称，形成可控的闽粤开局冲突。
- 粤国可以竞争“海道方伯”，以舰队、商税、运粮和海外港口而非纯陆军贡献盟功。
- 南海神庙成为海疆备援与国家海祭的象征，但其现实朝代起源文案需要改写。

### 待定事项

- 游戏内正式国名、统治者爵号及英文译名。
- 梁氏如何取得粤国政权，以及梁守谦自称岭南王的准确年代。
- 粤国开局是否拥有海南全岛、雷州及香山当前范围。
- 潮州冲突是核心、宣称、停战还是边境事变。
- 广东理念中征服与文化同化类加成是否保留。
- 海道方伯是全国方伯的海上职能，还是并立的第二职位。

### 广州贸易特性

`gdd_guangzhou_trade_hub` 已经存在。它在国家作用域检查对广州省份667的所有权，并给予拥有者：

- 贸易效率 `+10%`。

因此它在技术上是“由广州所有权触发的国家特性”，不是只作用于广州本地数值的省份修正。这个设计适合保留：任何控制珠江口与广州贸易制度的国家都能获得收益。

### 南海神庙与扶胥古港

`gdd_nanhai_temple` 已经作为广州的三级奇观存在，并拥有自制界面资产。当前机制包括：

- 不能迁移；
- 使用与升级要求拥有广州核心，并接纳粤语文化；
- 一级强化本地贸易力量、船员及贸易船力量；
- 二级增加贸易引导、船员与贸易船力量；
- 三级要求三级贸易中心，并在马来亚或印度尼西亚拥有至少三个合格港口；
- 三级提供更强的贸易与水手加成，并增加一名商人。

这套玩法与粤国海疆路线高度兼容，原则上应保留。需要改写的是当前文件中“公元594年、隋文帝时期始建”的现实历史定位，因为本世界线未必存在隋朝。

推荐的新叙事是：南海神祠源于周盟早期的南海祭祀传统，历经岭南诸侯、海商会馆和国家海祭多次扩建；扶胥古港则是粤国向周盟输送海外粮食、军资与移民的制度中心。准确始建年代待世界线时间线确定后再写。

### 广东理念

当前 `GDD_ideas` 包含：

| 项目 | 当前效果 | 迁移建议 |
|---|---|---|
| 传统 | 继承人概率、正统性 | 可保留，支持梁氏政权稳定叙事 |
| 南海开拓 | 殖民队、殖民成功率 | 保留，是海疆备援主轴 |
| 商业贸易 | 贸易效率 | 保留 |
| 海滨子弟 | 全国水手 | 保留 |
| 南方拓土 | 核心化花费 | 待审，避免只奖励无差别征服 |
| 私家武装 | 纪律 | 可保留，但需补充宗族、团练或海防背景 |
| 粤语传承 | 文化转化花费 | 建议重做；与多元诸夏主题存在冲突 |
| 百味生香 | 生产效率 | 保留并强化港口、手工业或香料叙事 |
| 野心 | 商人 | 保留 |

“文化转化花费降低50%”尤其需要重审。推荐改为接纳文化、文化槽位、最大可接受文化阈值或异文化省份稳定类效果，使粤国可以建设多文化海洋共同体，而不是成为最高效率的文化清洗国家。

### 奉贡藩国与地方藩国改革

当前 `gdd_invested_tributary` 复制原版朝贡国类型，已经具备以下适合作为原型的特征：

- 不占宗主国外交关系；
- 不自动参加宗主战争；
- 不能被正常外交吞并；
- 原版朝贡国基础允许同一宗主下的成员互战、结盟、联姻和宿敌。

但它目前要求宗主是中华帝国皇帝，并把明朝设为GDD宗主。这与新世界线不兼容。

迁移时不应直接删除该文件。推荐先建立跨诸夏的 `zhx_` 特殊成员类型并完成测试，再把GDD从旧类型迁移过去。现有“地方藩国”一级改革也应改造成所有奉册诸侯可以使用的通用制度，或改为粤国专属的岭南封国改革。

### 必须重写的现实时间线内容

以下内容依赖明、清或现实朝代，应视为迁移债务：

- 明朝与GDD的宗属关系；
- 开局五年停战与后续和约事件链；
- “脱离华夏—大逆不道”中以明帝国为中心的叙事；
- 针对违制藩国的旧战争借口；
- 各省历史中1444年后的明、清、三藩和葡萄牙所有权记录；
- 南海神庙的隋代始建日期与说明；
- 书签中以明朝分裂为背景的开局介绍。

这些文件在全国地图重构前不宜零散删除，否则会暂时破坏现有广东版本。迁移应在独立阶段集中完成。

## 粤国的1444年身份

### 推荐政治叙事

梁氏通过平定海寇、控制珠江口税关和调和岭南地方势力取得粤国政权。周室为了换取海运、贡赋与南疆稳定，承认梁守谦为粤公；梁守谦则凭实际实力和国内拥戴自称岭南王。

这让粤国同时拥有三种合法性：

1. 周室册封提供的诸夏法统；
2. 平乱与护航带来的军功合法性；
3. 广州商人、宗族和沿海军户提供的地方支持。

玩家必须决定哪一种合法性居于首位。

### 开局地缘关系

- **闽**：控制潮州，既是海贸竞争者，也是最自然的联盟对象。
- **桂**：控制岭南西部与山地通道，不是粤国的天然附庸。
- **湘与楚**：决定岭南进入长江流域的陆上通道。
- **大越与占城**：既能提供粮食、港口和盟友，也会反制粤国的扩张。
- **周室**：需要粤国的财政、舰队和海外供给，却可能拒绝承认岭南王号。
- **秦**：希望粤国承担实质援助；粤国则可能要求以海道职权和贸易特许换取出资。

## 开局事件与决策方向

### 开封大朝会中的粤国选择

斡罗斯危机爆发后，粤国不应只有“参战／不参战”两个选项。推荐提供四类贡献：

| 选择 | 即时成本 | 主要收益与后果 |
|---|---|---|
| 派遣岭南军 | 人力、金钱和可能的远征损耗 | 大量盟功、军事声望，与秦关系改善 |
| 输送海贸军饷 | 金钱、贸易收入或通货膨胀 | 盟功、周室信任、贸易特许 |
| 接纳西陲难民 | 短期动乱和财政压力 | 发展、人才、文化事件与殖民人口 |
| 拒绝共同义务 | 礼统与关系损失 | 保存国力，强化自主或问鼎路线 |

### 潮州争端

推荐把潮州设计成可通过多种方式解决的开局矛盾：

- 接受周室仲裁；
- 向闽购买或交换潮州；
- 支持本地粤系势力；
- 以保护海运为由发动有限战争；
- 与闽成立共同关税区。

潮州不应只是免费核心战争。它应成为周盟能否约束成员冲突的第一个小型案例。

### 王号争议

梁守谦专属“岭南王”称号可以保留，但重写为周盟法统冲突：

- 接受粤公封号：获得礼统、外交与盟功收益；
- 继续私称岭南王：获得威望与国内正统，但降低周室信任；
- 请求加封：以援秦、海运或方伯军功换取正式王爵；
- 自立南海王：进入更激进的独立或问鼎路线。

## 四条长期玩法路线

### 尊周勤王

粤国以财政、舰队和粮道支持周室，推动较制度化的诸夏共同防御。终局可以成为周盟的首席海权国、获得世袭海道职权，并帮助形成稳定的列国联邦。

### 争任海道方伯

粤国证明“守天下不只有西北骑兵”。通过保护航路、镇压海盗、建立海外补给港和完成共同运输任务积累盟功，迫使传统陆权诸侯承认海权也能领导共同防御。

### 岭南霸府

粤国整合桂、潮州和南海沿岸，以广州财富建立南方霸府。它可以挟周室改革盟约，也可以逐步走向问鼎和统一。

### 海上新天下

粤国把难民、军户、商人和宗室迁往海外，建立侨州与封国。后期核心问题不是占领多少空白土地，而是海外封国能否参加开封王会、是否与本土诸侯平等，以及粤国是否愿意放弃宗主地位。

## 南海神庙在新世界线中的作用

南海神庙可以同时承担三个层次的功能：

- **地方层**：广州港、扶胥古港和珠江口航运的保护神祠；
- **国家层**：粤国舰队、商旅与海外开拓者出发前的国家祭祀中心；
- **周盟层**：周天子举行南海遥祭、承认海道方伯或海外封国的象征场所。

未来事件可包括：

- 西陲难民抵达南海神庙；
- 周使册立海道方伯；
- 海商要求扩大祭典代表权；
- 海外封国献上新航路图；
- 斡罗斯东正教使团参观国家海祭，引发礼仪争论。

这些事件均为设计提案，当前尚未实现。

## 广东迁移完成标准

只有满足以下条件，才能把广东视为已经迁入新世界线：

1. 1444年不再依赖明朝作为宗主或历史背景；
2. GDD正确成为周盟成员，并可与其他成员正常外交和战争；
3. 梁氏、王号和开局事件全部使用新世界线叙事；
4. 广州贸易特性与南海神庙在新地图上正常生效；
5. 潮州、桂国、闽国和周室外交关系已经落地；
6. 旧明清日期历史不会覆盖架空存档中的预期结果；
7. 至少一条援秦路线和一条海疆路线可完整游玩；
8. 新游戏、存档读取及主要DLC组合完成实机验证。
