# 礼教主学派更张：2026-08-28 阶段性实机证据

## 环境

- EU4 `1.37.5.0 Inca`，`religion` 分支，新开 1444 战役。
- 以秦国作为礼教测试国；使用不接入 `on_action`、决议或启动流程的临时控制台事件压缩五年／十年等待。
- 本目录证明的是首版主流程抽检，不代表 `planning/religion_reform/runtime_test_matrix.md` 的全部边界已经跑完。

## 已验证流程

1. 儒家为主、仅法家受邀时，“广开新论”目录只放行法家，并保留翻页与退出入口。
2. 法家确认卡正确说明五年培植、培植期惩罚、正式采用的稳定与威望成本，以及新学从 `15` 践履起步。
3. 培植期宗教页仍以儒家为主；正式采用后法家成为主学派，旧儒家以无数值第二徽章保留。
4. 成功样本以践履 `50`、稳定度达标结算，旧学第二徽章被清除。
5. 失败样本以践履 `24` 结算，只出现“再推新学五年”和“迎还旧学”两个实质出口。
6. 选择迎还后，儒家恢复为主学派、践履为 `25`，失败的法家进入十年第二槽。
7. `1180×768` 下目录、确认卡、正式采用、失败双出口和宗教页徽章均无文字裁切、按钮溢出或徽章堆叠。
