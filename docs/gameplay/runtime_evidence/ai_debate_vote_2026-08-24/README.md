# 天下大辩 AI 投票与悬停票单实机验收

- 验收日期：2026-08-24
- 游戏版本：EU4 1.37.5.0
- 分支：`religion`
- 样本候选：甲案墨家、乙案道家
- 合资格国家：67（玩家周天子 1，AI 66）

## 验收结果

1. 开票动作完成后、玩家尚未投票时，AI 已同步投出 66 票：甲 13、乙 9、并立 44。
2. 玩家投甲后，票盘为甲 14、乙 9、并立 44；悬停明确显示“已投国数 67／应投国数 67”。
3. 甲案票单列出 14 个支持国，每国显示 `×1` 票重。
4. 玩家改投并立后，票盘为甲 13、乙 9、并立 45；并立票单列出 45 个支持国并继续显示 67／67。
5. 投票按钮的引擎效果说明与触发条件已经隐藏；悬停框只保留实时票盘、投票完成度、国家名单和票重，没有脚本文本堆叠或裁切。
6. 最终重新启动至主菜单检查日志，`zhx_council`、`zhx_debate`、`hidden_effect` 与 `hidden_trigger` 均未产生新增错误；EU4 随后正常退出并确认进程关闭。

中立国家的 40／40／20 后备选择含随机性，因此不同测试局的甲乙丙分布可以变化；硬性验收项是所有合资格 AI 都必须在玩家看到面板前完成首投。
