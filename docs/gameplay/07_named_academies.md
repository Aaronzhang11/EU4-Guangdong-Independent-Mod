# 具名学宫：省份思想载体与国家协同

## 实现状态

十二座开局学宫及首版生命周期已经接入 `religion` 分支并通过专项静态契约；本轮 EU4
阶段性实机回归已于 2026-08-27 12:00 收束。当前闭环包括地方收益、国家协同、思想张力、容忍、三年逐学、撤令、
外交反应、跨国庇护、迁徙、遗址、流散复兴和谨慎的 AI 逐学。实现以全新
`1444.11.11` 战役为边界，不为开发期旧存档补做初始化迁移。

一句话介绍：**学宫是省份里的具名思想机构，而不是另一种省份宗教。**它无论由谁统治
都会给所在省份带来教育与知识传播收益；若与国家主学派一致，就让学术网络与朝廷形成
一份不叠加的国家协同；若既不属于主学派，也未被受邀第二学派保护，则按异派种类制造
思想张力。国家可以容忍或驱逐这些机构，别国也可以庇护流亡诸生；学宫迁往别处后仍保留
固定专名，并在原址留下可见遗址。

## 一、状态边界

- 学宫的唯一玩法真值是其所在省份上的唯一永久修正，例如
  `zhx_academy_chongli`；学宫名、学派和效果不复制进省份宗教槽。
- 主学派仍只读取六个 `zhx_doctrine_*` 国家旗标。
- 受邀第二学派仍只读取六个 `zhx_*_invited_scholar_modifier` 限时修正。
- 原生 `religious_school` 只是主学派徽章的显示镜像，不能参与学宫判定。
- 学宫专名不含地理名。迁徙只改变永久修正所在省份，不修改学宫名称。
- 当唯一永久修正暂时不在地图上时，对应的 `zhx_academy_dormant_*` 全局旗标只表示该
  学统处于流散状态；逐学、邀约和结算旗标全部是可清理的过程或呈现状态。

策划层权威表位于
`planning/religion_academies/academy_manifest.json`；专项校验器要求它与省份历史、修正、
触发器、同步入口和汉化逐项一致。

## 三、地方收益

所有活跃学宫无条件提供：

- 本地发展成本 `-5%`；
- 本地思潮传播 `+15%`。

各家再提供一项地方特色：

| 学派 | 学宫特色 |
|---|---|
| 儒 | 本地税收 `+10%` |
| 法 | 本地治理成本 `-10%` |
| 墨 | 本地建设成本 `-10%` |
| 道 | 本地叛乱度 `-1` |
| 兵 | 本地人力 `+15%` |
| 纵横 | 本地贸易力量 `+15%` |

地方收益与统治者国教、主学派和第二学派无关。非礼教国家征服学宫后仍能使用其地方
教育网络，但不会进入礼教国家的协同与思想张力计算。

## 四、国家协同

礼教国家只要拥有至少一座与主学派相同的学宫，就获得一份固定协同；同派第二座及以后
不会叠加。协同复用对应受邀学派的入门级数值，但使用独立修正键，生命周期互不干扰：

| 主学派 | 国家协同 |
|---|---|
| 儒 | 顾问花费 `-2.5%`；稳定度花费 `-2.5%` |
| 法 | 月度自治度变化 `-0.025`；造核花费 `-2.5%` |
| 墨 | 要塞维护费 `-5%`；要塞防御 `+5%` |
| 道 | 全国叛乱度 `-0.5`；月度厌战 `-0.01` |
| 兵 | 人力恢复速度 `+5%`；陆军传统衰减 `-0.5%` |
| 纵横 | 改善关系 `+10%`；外交声誉 `+0.25` |

受邀第二学派不会授予这份学宫协同。它本身已有二十年弱化增益，在学宫系统中只承担
“承认并保护同派学宫”的作用。

## 五、思想张力

系统统计境内**未受保护的不同学派种类**，不统计学宫座数。同一异派拥有一座或两座
学宫都只计一；主学派或受邀第二学派会保护对应学派的全部学宫。

| 未受保护学派种类 | 状态 | 国家效果 |
|---:|---|---|
| 0 | 无 | 无惩罚 |
| 1 | 百家异响 | 稳定度花费 `+15%`；全国叛乱度 `+0.5`；治理容量 `-5%`；分离主义 `+2` 年 |
| 2 | 思想纷争 | 稳定度花费 `+30%`；全国叛乱度 `+1.5`；治理容量 `-10%`；分离主义 `+5` 年 |
| 3—6 | 百家鼎沸 | 稳定度花费 `+50%`；全国叛乱度 `+3`；治理容量 `-20%`；分离主义 `+10` 年 |

第三档硬封顶，避免吞并多个思想中心后出现不可恢复的线性惩罚。治理容量与分离主义让
容忍异派成为明确的扩张约束，但仍不额外提高造核花费；逐学与庇护直接改变活跃学宫
驻地并刷新这套张力状态，不另建立省份学派人口值。

## 六、容忍、逐学与撤令

玩家境内存在未受保护学宫时，可通过“处置异派学宫”决议打开两页名册。关闭事件即继续
容忍：学宫保留完整地方收益，但其所属异派继续计入全国思想张力。每次只能对一座学宫
颁布逐学令，条件与代价为：

- 和平、至少 `1` 稳定度、`30` 行政点；
- 失去 `30` 行政点、`1` 稳定度与 `5` 威望；
- 三年内全国叛乱度 `+0.5`、稳定度花费 `+5%`；
- 目标省份叛乱度 `+3`、发展成本 `+5%`、思潮传播 `-10%`，税收、生产与人力各 `-5%`；
- 奉行该派或已延请该派的礼教国家对逐学国获得 `-50` 意见和固定 `10` 侵略扩张。

这一版把逐学的行政与威望负担调低，但保留 `-1` 稳定度这一硬成本；容忍则承受显著
增强且带有反扩张性质的思想张力。两条路线因此都有长期代价，驱逐也不会成为可连续
点击的无脑清场按钮。

三年到期时会再次核验：若目标学派已经成为本国主学派或受邀第二学派，逐学自动止息，
学宫留在原址；否则学宫离境并进入庇护流程。玩家会收到明确的到期结果事件。玩家也可
提前使用“撤销逐学令”保住学宫，但此后十年不能再次逐学。主动撤令会先保存受压学宫的
专名与原址，完成压力清理、十年冷却和国家效果刷新后，再同步显示“撤销逐学令”回执；
回执说明学宫留在原址，并可直接定位该省。玩家确认后清理临时呈现状态。目标省份易主会
按“具名学宫身份 + 原持有国对应逐学旗标”清除原持有国的国家级逐学状态，再防御性移除
省份压力；不会伪装成玩家主动撤令或弹出这张回执。身份判断不依赖易主时可能已被引擎
清除的临时压力修正，也不会因为原持有国正在别处逐学而误取消另一道逐学令。

## 七、庇护、迁徙与复兴

被逐学宫依次寻找一名合格庇护者：先找同主学派国家，再找已经延请该派的国家，最后找
对逐学国意见至少 `+50` 的其他礼教国家。候选国可以接纳或拒绝；接纳后自动选择没有
活跃学宫、遗址或逐学压制的城市，优先发展度至少 `20`，其次至少 `12`，最后才使用任意
合格城市。求庇选择会在候选国确定后同步打开，避免被普通事件队列遮住。新驻地获得同一
座具名学宫的永久修正，名称与学派不变。若接纳者是玩家，安装成功后会同步收到“学宫
落脚”国家回执；落点分支只为玩家保存一次临时全局省份目标，随后由仍处于玩家国家作用
域的接纳选项同步打开回执，明确显示具名学宫与新驻地。玩家确认后即清除临时目标；AI
接纳者既不保存目标，也不会收到这张纯呈现事件。回执同时使用原生省份定位入口，玩家
可以直接把镜头移到新讲席，不必再按名字查找省份。

原址留下具名遗址并获得思潮传播 `+5%`。无人接纳、候选国没有合格城市或候选国拒绝时，
学统保持流散而不是永久删除。“婉拒其请”的结果悬停会在选择前明确说明：学宫不会迁入
本国、不会被删除，而是保持流散；当前天子每年有 `10%` 概率尝试为其另寻庇护，没有
合格礼教国家接纳时则继续流散。年度复兴仍按同派、受邀同派、其他礼教国的顺序寻找新
驻地；若每年都持续存在合格候选且最终愿意接纳，单座学宫的抽签平均等待约为十年，
否则可能更久。

AI 只有在和平、稳定度至少 `2`、行政点至少 `100`、境内至少两种未受保护异派，且没有
逐学或撤令冷却时，才有每年 `8%` 的机会开始一次随机逐学。此门槛用于避免列国无差别
清空思想地图。

## 八、同步与性能

- 新开局分配主学派后立即计算一次；
- 改换主学派后立即计算一次；
- 延请或改请第二学派后立即计算一次；
- 学宫省份易主时，只刷新新旧两个持有国；
- 每年在国论归一后进行一次低频修复，用于处理受邀学派自然到期等情况。

地图重放的正式末端入口是
`tools/map_pipeline/finalize_zhx_province_history.py`。所有会重建省份历史的地图、版图、
文化、发展度、地名与宗教脚本结束后，先无参数运行该入口恢复宗教地理和十二宫落点，
再以 `--check` 复核；不得在它之后继续运行省份历史 writer。

普通省份易主不会扫描学宫；月度悬停缓存也不读取学宫。二十年受邀修正自然到期没有
原生脚本回调，因此思想张力最多在下一个年度脉冲才恢复，这一可控滞后换取了更清楚的
低频状态机。

## 九、延期内容

以下内容已有方向，但不属于首版可玩闭环：

- 六家各自最多再动态出现一座学宫；
- 学宫合流学说与后来外教入礼产生的新正式学派；
- 战争中强迫敌国停止逐学的专用和平条款；
- 面向玩家的全天下流散学宫总览；
- 独立学宫页面或地图图层。
