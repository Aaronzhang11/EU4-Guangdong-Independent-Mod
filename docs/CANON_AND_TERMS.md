# 正典规则与术语表

## 文档目的

本文件规定知识库中不同设定的权威等级，并统一后续文案、事件和代码使用的核心术语。

## 正典等级

### 已定设定

以下内容构成当前世界线的硬前提：

- 秦国没有统一六国。
- 周室没有被彻底消灭，并延续到1444年。
- 诸夏长期处于政治分裂状态，地方诸侯名义尊重周天子，实际上各自为政。
- 诸夏不仅政治分裂，也形成了显著的地域文化和思想差异。
- 1444年前后，一支东迁的斯拉夫背景势力侵入中国西北，并占领秦国部分土地。
- 这场入侵引发诸夏的制度危机、文化焦虑和对海外生存后方的讨论。
- 当前广东模组将扩展为这一世界线的 EU4 模组，而不是另建完全无关的项目。
- 礼教是诸夏内部承载诸子百家的共同接口，不是整个东亚或全部周天下成员的默认宗教。
- 儒、法、墨、道、兵、纵横是礼教国家可以改换的国论学派，不是需要批量转换省份的六种互斥宗教。
- 周天下政治成员、国家宗教与礼教学派是三套独立身份；辽信仰景教，高丽及其全部开局省份信仰大乘佛教。

### 工作设定

以下内容是目前最推荐的解释，后续设计默认采用：

- “东迁斯拉夫游牧民族”是以罗斯语言、东正教传统和斯拉夫军户为认同核心，吸收钦察、阿兰、乌戈尔及蒙古部众的复合草原共同体。
- 诸夏称这一共同体为“斡罗斯”或“斡罗斯诸帐”，其国家暂称“斡罗斯大帐”。
- “周联邦”只作为现代设计语言；世界内部主要使用“周盟”“诸夏王会”“成周盟约”等名称。
- 周天子与方伯／霸主是两个不同角色：天子掌法统，方伯掌军事执行权。
- 1444年周王朝以东京开封为行政首都，直辖东京王畿与成周区域共八省；洛阳称“成周”，保留宗庙、旧盟坛与礼制中心地位。
- 1444年的斡罗斯入侵是周盟首场大型“天下事变”，也是模组的开局教学危机。
- 海外扩张首先表现为港口、屯垦、侨州和海外封国，随后才演化为近代殖民帝国。
- 周盟系统采用自定义脚本实现，欧洲神圣罗马帝国继续存在。

### 待定事项

- 模组最终中文名与英文名。
- 秦未统一的精确历史分歧点。
- 周室在历次蒙古征服中的具体地位。
- “洛阳再盟”的准确年代和签约国家。
- 1444年全部国家的精确边界、标签、统治家族与发展度。
- 周盟世界内正式法律名称。
- 方伯任期、选举人数量与投票规则。
- 斡罗斯统治者、王朝名称、旗帜与宗教细节。
- 周盟改革树最终采用线性、分支还是混合结构。
- 海外封国能否自动取得与本土诸侯平等的会盟席位。

## 核心术语

| 术语 | 定义与使用规则 |
|---|---|
| 诸夏 | 共享部分礼制、经典与历史记忆的文明共同体，不等同于现代单一民族国家 |
| 天下 | 诸夏政治想象中的秩序空间，可随礼制、人口和册封关系向海外扩展 |
| 周盟 | 周天子主持、诸侯共同参加的松散政治秩序总称 |
| 周联邦 | 方便设计讨论使用的现代分析词，不宜大量出现在游戏内古风文案中 |
| 成周盟约 | 周盟成文制度或洛阳会盟传统的候选正式名称 |
| 周天子 | 世袭礼制共主，掌祭祀、册封、仲裁与秩序合法性 |
| 方伯 | 经会盟认可的阶段性军事领导人，强调合法授权 |
| 霸主 | 方伯权力膨胀后的政治称谓，也可作为未获周室完全承认的事实领袖 |
| 奉册诸侯 | 接受周室册封、属于周盟，但保留广泛自主权的成员国 |
| 议政诸侯 | 在朝会、方伯推举或盟约表决中拥有特殊席位的诸侯 |
| 礼邑 | 因宗庙、圣贤或礼制地位受到特别保护的小国，例如鲁 |
| 通商公邑 | 受周盟保护并承担贸易、金融或会议功能的城市政体 |
| 礼统 | 周室及周盟秩序的合法性和执行能力，建议作为0—100的全局数值 |
| 礼教 | 诸夏国家共同讨论名分、治国与天下责任的宗教—礼制游戏接口；其具体实现是诸子百家 |
| 国论 | 礼教国家当前采用的主要学派和治国路线，可经国内大辩改换 |
| 践履 | 国家是否真正按当前国论行事的 0—100 数值；收益来自长期实践而非花钱购买 |
| 盟功 | 单个诸侯对共同防御、财政、难民安置和盟约执行的贡献 |
| 天下事变 | 需要诸侯表态和共同决策的跨国危机 |
| 斡罗斯 | 诸夏对东迁罗斯—草原复合共同体的传统称呼 |
| 海疆备援 | 通过海外粮仓、港口、舰队基地和侨民聚落建立战略后方 |
| 海上分封 | 周室或诸侯把宗室、功臣和移民编为海外封国的制度 |
| 问鼎 | 否定周室法统、争夺天下最高主权的政治行动 |

## 连续性约束

### 国家与历史

- 1444年的秦、齐、燕、吴、越等名称主要是地域爵号或政治传统，不意味着先秦王室连续统治一千七百年。
- 统治家族、疆界、制度和族群构成都应经历多次变化。
- 蒙古帝国等欧亚级征服仍可发生，但周室可像礼制人质、祭祀机构或受保护王家一样延续。

### 文化

- 不存在单一、完全同质的“中国文化”。
- 诸夏仍应拥有足以支撑外交、经典传播和共同政治想象的跨地域文化层。
- 儒、法、墨、道、兵、纵横等首先是礼教内部的思想与制度差异，不改造成六种互相敌视的省份宗教。
- 非华夏国家不会因为位于中华大区、使用某个文化组或参加周天下政治就自动信仰礼教。

### 斡罗斯

- 不写成纯斯拉夫人口突然横跨欧亚并集体游牧化。
- 不把“斯拉夫”作为诸夏人在1444年的常用自称或他称。
- 不把斡罗斯设定为只有破坏欲的终极反派。
- 必须保留其迁徙压力、定居需求、内部派系和受册封可能性。

### 殖民

- 不采用“西北失地后立即前往美洲”的跳跃因果。
- 殖民必须经过难民迁徙、贸易转向、港口屯垦和海外封国等阶段。
- 应描写诸夏扩张对海外原有社会造成的影响，保留反抗、融合、协商和平等入盟等可能。

### 游戏实现

- 欧洲神圣罗马帝国不因周盟系统而被删除。
- 不声称可以新增第三个引擎原生帝国类型。
- 自定义外交行动、成员列表、战争领袖和地图模式的硬限制必须如实记录。
- 在没有实机验证前，不把脚本可解析等同于玩法已经稳定。

## 修订流程

1. 新想法先以“提案”写入相应文档的待定章节。
2. 用户明确确认后，将其升级为已定设定，并在决策记录中新增条目。
3. 若新设定与既有已定设定冲突，应先解释冲突，再修改旧条目。
4. 代码实现完成后，更新对应文档的“实现状态”，不改变其正典等级。
