# 设定决策记录

本文件记录会影响多个文档、地图或系统的关键选择。日期使用当前项目工作日期，不代表世界内年代。

## 2026-07-23

### D-001：项目扩展为诸夏列国世界线

- **状态**：已定
- **决定**：当前广东独立模组将扩展为“秦未统一、周室延续、诸夏列国并立”的大型架空历史模组。
- **影响**：广东不再以反明独立为主要历史背景，而成为周盟中的岭南诸侯。

### D-002：周室与地方诸侯长期并存

- **状态**：已定
- **决定**：周天子保留名义与礼制权威，诸侯拥有事实主权，整体具有类似神圣罗马帝国的分权观感。
- **影响**：统一中国不应是开局默认状态，而应是玩家可以争取的终局之一。

### D-003：周天子与方伯／霸主分离

- **状态**：工作设定
- **决定**：周天子掌法统并世袭；方伯由会盟产生，负责共同防御与军事执行。
- **理由**：比直接复制神罗皇帝选举更符合周代政治语言，也能形成双元权力冲突。

### D-004：斡罗斯采用复合草原共同体解释

- **状态**：工作设定
- **决定**：1444年的入侵者不是纯斯拉夫游牧民族，而是以罗斯语言、东正教传统和斯拉夫军户为认同核心的斡罗斯—钦察复合大帐。
- **影响**：其文化、军制、宗教、人物和任务树必须体现内部多样性。

### D-005：斡罗斯入侵成为1444年开局危机

- **状态**：已定方向
- **决定**：斡罗斯已经占领秦国部分西北土地，并由此触发诸夏制度与思想危机。
- **待定**：具体省份、战争是否在开局仍在进行、秦国是否存在继承危机。

### D-006：殖民由多阶段危机推动

- **状态**：工作设定
- **决定**：殖民动力遵循“西陲失守—陆路受阻—难民迁徙—海外备援—海上分封—殖民竞争”的链条。
- **影响**：不同诸侯拥有不同扩张方向；内陆国家不被强迫采用海洋殖民路线。

### D-007：周盟使用自定义系统

- **状态**：工作设定
- **决定**：不迁移或删除欧洲神罗。周盟采用自定义变量、旗标、特殊属国、事件、外交行动、战争借口和GUI实现。
- **技术边界**：EU4不能注册第三个原生 `empire` 对象，目标是功能高度相似，而非引擎层复制。

### D-008：保留现有广东资产

- **状态**：已定
- **决定**：保留 GDD、广州贸易特性、南海神庙资产、广东理念与梁氏人物基础。
- **需要改写**：反明叙事、明朝宗属关系、南海神庙“始建于隋代”等现实时间线文本。

### D-009：中华大区进行全域温和细化

- **状态**：已定方向
- **决定**：中华大区不只细化广东和河西，而是进行一次覆盖北中国、西南中国和南中国的温和拆省；先完成总表，再按区域绘制。
- **工作目标**：以 EU4 1.37.5 的110省为基线，第一轮新增50省，形成160省的中华大区。
- **数值原则**：拆省阶段基本保持母省发展度守恒；全国经济强化另做独立校准，避免同时改变地图密度与初始国力。
- **实现状态**：总表、绘制批次以及数字省份ID与RGB登记表已经建立；广东八个新增省已经部署到正式地图资产并通过静态校验，其他区域批次尚未绘制。

### D-010：香港纳入广东首批拆省

- **状态**：已由 D-012 的惠州四向拆分扩展
- **决定**：香港作为 B01 的第五个新增省份，与东莞一起从原惠州 2157 一次性拆出；1444 年发展度设为 `1/1/1`。
- **地图原则**：香港位于东莞东南、惠州南缘，以新界—九龙沿岸抽象其可点击范围；第一轮不修改原版海岸线。
- **数值原则**：首版曾采用惠州 `3/3/1`、东莞 `3/3/1`、香港 `1/1/1` 的守恒三拆；D-012 加入陆丰后改为四向拆分。

### D-011：首批五省采用独立可玩切片部署

- **状态**：已由 D-012 扩展
- **决定**：首批程序生成地图只开放佛山、东莞、梅州、高州和香港五省，使用 `4942–4946` 与 `max_provinces = 4947`；后续预留 ID 不以空省份进入游戏。
- **资产范围**：完整省份图、定义表、点位、Area、Region、洲、气候、地形、贸易节点、贸易公司、省份历史和本地化同步部署。
- **兼容边界**：地图基线锁定 EU4 1.37.5；与其他覆盖中国地图核心文件的模组不兼容。

## 2026-07-25

### D-012：广东手绘地图成为正式权威底图

- **状态**：已实现并通过静态校验；编号上限已由 D-013 扩展
- **决定**：玩家直接编辑的正式 `map/provinces.bmp` 是广东地图后续工作的 canonical source。程序生成的 B01 轮廓和预览文件只保留为历史记录，不得再运行旧生成器覆盖手绘省界。
- **省份编号**：佛山、东莞、梅州、高州、香港继续使用 `4942–4946`；罗定、南雄、陆丰依次使用 `4947–4949`；`default.map` 使用 `max_provinces = 4950`，不把其他规划省份作为空省暴露给游戏。
- **地图范围**：广东正式新增省由五省扩大为八省。广东相关省份总数为十八，其中GDD在1444年控制十七省，潮州由明朝控制并保留GDD核心。
- **罗定**：从肇庆665拆出，发展度 `1/1/1`，粤文化、儒教、谷物，首府使用1444年更合时宜的“泷水”；肇庆调整为 `3/3/2`。
- **南雄**：从韶关2158拆出，发展度 `2/1/1`，客家文化、儒教、谷物，首府“保昌”，并设一级内陆贸易中心以表现梅关商路；韶关调整为 `2/3/1` 并保留铁矿。
- **陆丰**：行政上从惠州2157拆出，发展度 `1/1/1`，闽南文化、儒教、盐，首府“碣石”；拥有港口和十五世纪要塞，不增加闽核心，以维持潮州作为闽粤主要争议区；惠州调整为 `2/2/1`。
- **数值原则**：肇庆组与韶关组发展度严格守恒；惠州—东莞—香港—陆丰组税收与生产严格守恒，人力由 `3` 增至 `4`。在每省三项基础发展度至少为1的约束下，本轮全图只净增1点人力。
- **验证边界**：定义、像素颜色、连通性、Area、Region、洲、气候、地形、贸易、省份历史、本地化与点位已经通过静态校验；必须以全新1444年游戏继续检查地图加载、点击、港口、要塞、贸易中心、保存与读档。

### D-013：东南十二省优先准备但不代画正式边界

- **状态**：非 BMP 资产已实现，等待用户手绘
- **决定**：浙江使用湖州、台州、衢州，福建使用莆田、漳州、邵武、厦门，
  广西使用浔州、庆远、太平，台湾使用诸罗、噶玛兰，连同各地原版省份，使浙江、
  福建、广西各达到 8 省，台湾达到 5 省。十二个新省接续使用 `4950–4961`；
  其他尚未绘制省份只调整数字 ID，既有设计键和 RGB 均保持不变。
- **几何边界**：本批不得改动 canonical `map/provinces.bmp`。构建器只写定义表、
  区域、地形、贸易、点位、历史与本地化，并把几何状态标记为
  `awaiting_user_pixels`。
- **数值原则**：浙江、福建和台湾按母省组守恒；广西按整个 Area 统筹，柳州组三拆
  多出的 1 人力由梧州转出，Area 总量仍为 `8/8/9`。四地区整体不增加发展度。
- **Area 拆分**：广西拆为左江（南宁、太平、浔州、梧州）与右江（凌云、柳州、
  庆远、桂林）；福建拆为福建东部（福州、泉州、莆田、漳州、厦门）与福建西部
  （建宁、汀州、邵武）。为兼容原版脚本，内部键 `guangxi_area` 与 `fujian_area`
  分别保留给左江和福建东部。
- **政治边界**：在越、闽、桂等新标签建立前，大陆五省暂继承当前有效国家与原版
  区域核心；诸罗保持未殖民的台湾诸社。不得提前写入无效国家标签。
- **完成门槛**：用户手绘十二种 RGB 后，重新冻结像素数、连通块、邻接、海岸和
  点位断言，再进行全新 1444 开局与保存读取验证。

  分离主义延长 `2/5/10` 年，以形成明确但封顶的反扩张压力。
- **同步边界**：开局、改换国论、延请学派和学宫易主时立即刷新；年度脉冲在国论归一后
  低频修复。不会月度扫描全世界。受邀修正自然到期后允许最多滞后到下一次年度刷新。
