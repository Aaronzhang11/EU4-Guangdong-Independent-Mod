# B51 辽国实装

## 设定

辽国是政治上尊奉周室的契丹诸侯，但在 EU4 引擎中保持独立，不建立任何
subject/dependency。契丹统治集团使用 `gdd_khitan` 文化，不设置专属属国改革。

## 开局版图

辽国占据完整的 `liaoning_area`（显示名“辽东”）：

- 沈阳（726）
- 辽阳（5204，首都）
- 铁岭（5205）
- 九连城（2112）
- 海城（4652）
- 盖州（2113）

辽国共六省、58发展。燕国保留燕都、蓟北以及辽西的辽河套和广宁，共十一省、
123发展。宁远与锦州仍归无终，不把辽西或女真腹地并入辽国。

本批不修改省份几何、区域、贸易节点、贸易公司或贸易中心等级。
