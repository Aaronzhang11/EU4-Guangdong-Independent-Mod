# B19 福建十三省 GeoJSON 细化

本批次依据现代福建 84 个县级区划的 GeoJSON 边界，结合明清府州、主要河流与山脉，将福建正式细化为十三省、三个区域。用户手绘的厦门省份作为不可变几何保留。

## 三个区域

| 区域 | 省份 |
| --- | --- |
| 闽东 | 闽侯、福宁、福清、兴化 |
| 闽南 | 泉州、永春、厦门、漳州 |
| 闽西 | 建宁、邵武、延平、汀州、龙岩 |

## 地理依据

- 闽侯继承原福州省编号，以闽江下游和福州盆地为核心；名称改为闽侯，以免府名与省名层级混淆。
- 福宁沿闽东北海岸、霍童溪和鹫峰山脉展开。
- 福清连接闽江口南岸、福清湾与平潭方向；兴化以莆田—仙游盆地为核心。
- 泉州控制晋江下游港区，永春占据安溪、永春、德化和南安的戴云山腹地。
- 漳州统一九龙江流域和闽南南部沿海，不再单设漳浦。
- 建宁、邵武、延平分别依建溪、富屯溪和闽江上游河谷组织边界。
- 汀州沿汀江上游展开，龙岩以九龙江上游和龙岩盆地为核心。

## 游戏性设置

- 总发展度为 148。
- 闽侯为一级贸易中心并保留十五世纪要塞；泉州、厦门为二级贸易中心。
- 闽东以茶叶、鱼类为主；闽南配置瓷器、茶叶、鱼类和糖；闽西配置纸张、船具、铁矿和铜矿。
- 原福建八省编号继续使用；新增福宁、福清、永春、延平、龙岩，占用 `5096–5100`。
- `max_provinces` 提升为 `5101`。

## 厦门保护规则

- 编号保持 `4958`。
- RGB 保持 `135,45,225`。
- 保持用户手绘的 29 个像素，不按现代厦门市行政范围扩大。
- 保留原有城市与单位位置；仅补充发展度和二级贸易中心设定。
