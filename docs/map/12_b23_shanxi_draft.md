# B23 山西二十省与不可通行山脉正式方案

本方案参考创意工坊“大明日不落”MOD（`1728520255`）的 `provinces.bmp`，重点强化山西内部的地理与行政层次。宣化不纳入山西，蔚州地块并入代州；平阳以南拆出曲沃、绛州，原河东拆为蒲州、解州，最终形成二十个可通行省份、四个五省区域和五块山地省份。初版地图中全部可通行省份归还大明，不另设山西地方政权开局。

## 不可通行山脉

| 山系 | 地图实现 | 保留通口 |
| --- | --- | --- |

| 太行山 | 太行北山、太行南山两块山地省份 | 娘子关、壶关、天井关 |
| 吕梁山 | 吕梁山一块山地省份 | 汾河—离石方向山口 |
| 中条山 | 中条山一块山地省份 | 轵关陉、蒲津渡方向 |

五块山地省份均已加入 `impassable`，发展度为零、不归属国家、不加入普通区域。二十个可通行省份仍通过雁门关、娘子关、壶关、天井关等通道保持为一个连通网络。
