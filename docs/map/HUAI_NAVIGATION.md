# 淮河可通行水道实装记录

## 几何来源与路线

淮河几何参考创意工坊项目 `2935149060` 的 `map/provinces.bmp`。参考图为
`6400×2560`，本模组为 `5632×2048`；淮河局部以 `x-448、y-21` 平移后与本图的
洪泽湖、淮安和黄海岸线吻合，因此六段河道按原图像素轮廓逐行复刻，而不是重新画
一条近似折线。

水路结构与参考模组一致：洪泽湖以西四段，洪泽湖以东两段，最东端从淮安方向直接
接入黄海。现有洪泽湖位置与参考图对齐，保留本模组原有湖形并改为可通行水域。

## 可复现与验证

几何由 `tools/map_pipeline/apply_huai_navigation.py` 复现。脚本内嵌平移后的逐行像素
区间，不依赖创意工坊文件继续存在，并可重复运行而不扩大河道。静态校验覆盖：

- 六段河道各自为单一正交连通块；
- 舰队锚点落在对应水域且高度不高于水位；
- 洪泽湖从 `lakes` 移入可通行水域；
- 河口与黄海正交相连；
- 八个沿岸陆地省份的港口落在对应河段并紧贴本省；
- 六处陆路过河邻接使用正确的中间水域。
