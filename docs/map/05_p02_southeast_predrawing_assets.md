## 当前状态

本批十二个新省的配套资产均已建立。正式 `provinces.bmp` 已开始按规划手绘：

继续实施。已完成几何的省份可以在地图中正常识别，仍标记为
`assets_ready_geometry_pending` 的省份则等待后续绘制。

## 边界语义

- 湖州从杭州西北侧划出，表现太湖南岸、苕溪水系和丝业腹地；杭州必须保留钱塘江
  湾、都会点、二级贸易中心和主体海岸。
- 浙江台州从温州北侧划出，向宁波方向形成独立湾区；温州必须保留瓯江口和城市点。
- 莆田位于福州与泉州之间的兴化湾，不得把福州城市点或主港口切走。
- 漳州从泉州西南侧划出，围绕九龙江下游和漳州湾；泉州保留原城市点。
- 浔州已从柳州东南划出，位于柳州、南宁与梧州之间的黔江—浔江节点，形成紧凑内河省份。
- 诸罗位于大肚以南、赤崁以北的台湾西南平原；保持未殖民，不预设大陆诸侯已经控制台湾。
- 衢州从金华西侧划出，沿衢江向仙霞关方向展开，不得切断金华与杭州的主体联系。
- 邵武从建宁西部划出；建宁保留建溪上游，邵武取得富屯溪和江西方向山口。
- 厦门使用已经画定的厦门岛及近岸港区，港口面向台湾海峡，并与泉州、漳州保持清晰边界。
- 庆远已从桂林西侧划出并与柳州相邻，表现宜山—河池山地；桂林保留城市点和东部主体。
- 太平已从南宁西南侧划出左江流域；南宁保留城市点和向东的主体通道。
- 噶玛兰从淡水东北侧划出兰阳平原，保留淡水西北海岸和原城市点；赤崁则保留台湾南端。
- 台湾山脉沿岛轴南北纵贯并采用自然弧线；淡水、噶玛兰、大肚、诸罗、赤崁
  分别围绕北、东、西北、西南和南部海岸，五省都保留有效港口点。

## 完成手绘后的验收

1. 十二种 RGB 均在 BMP 中出现，且没有未知混色；
2. 每省主体连通、可点击，没有非预期孤岛或单像素细线；
3. 台州、莆田、漳州、诸罗、噶玛兰拥有正确海岸；其他新省保持内陆；
4. 全部城市、单位、文字和港口点落位正确；
5. 更新几何配置中的像素数、连通块、邻接和沿海断言；
6. 重新运行构建器、静态验证器与本地化检查；
7. 使用全新 1444 开局检查地图日志、寻路、港口模型、保存和读取。
