# 地图设计资产

本目录保存《列国奉周》的地图源数据和绘制规范。设计文档与游戏实现必须分开标记；没有通过分区审图和实机验证的地图不得宣称已经完成。

4. [手绘拆省与正式实装标准流程](04_manual_map_implementation_workflow.md)：从设计冻结、像素绘制、联动资产到实机验收的可复用 SOP。
5. [拆省批次实施与验收模板](templates/province_split_batch_template.md)：后续每个绘制批次可直接复制填写的检查表。

9. [B16 安徽十七省细化](08_b16_anhui_detail.md)：淮颍、江淮、皖江、徽宁四区域，巢湖—无为拆分和长江、淮河渡口实装。
10. [B18 四川三十六省细化](09_b18_sichuan_detail.md)：九区域、县级 GeoJSON 边界、商品发展度及全部配套资产的正式实装。

16. [B54 长沙扩地与三公邑](25_b54_changsha_public_cities.md)：益阳、安化归长沙，常德、九江、汉阳分别建立独立的一字公邑。
17. [B61 边疆与域外政权旗帜](../../planning/frontier_polity_flags_b61/README.md)：为氐羌、苗、彝、白、藏、壮、黎、契丹、女真、蒙古及高丽等二十八国建立独立的纹样化旗帜体系。

- 中华大区细化方向：已确认。
- 110 → 160 省的第一轮方案：工作设定；南中国为 75 省、538 发展，全国为 1093 发展。
- 数字省份 ID 与 RGB：五十省冻结为 `4942–4991`；B01 使用 `4942–4949`，
  P02 东南十二省使用 `4950–4961`，其他规划顺延；既有设计键 RGB 保持不变。
- 分区绘图：B01 广东八省已手绘完成；P02 十二省等待用户手绘。
- 广东规模：十个原版省份增加为十八省。
- 正式 `map/` 资产：B01 八省已部署；P02 十二省除 BMP 外的资产已经部署并通过静态校验。
- B16 安徽：十七省正式像素边界与全部配套资产已部署并通过静态验证；芜湖预留自由市。
- B18 四川：三十六省正式像素边界与配套定义、历史、区域、位置和本地化已部署；新增编号为 `5075–5095`。
- B46 川东北—重庆：在 B18 外框内由 10 省细化为 22 省，新增编号为 `5329–5340`；五个 Area、六个本区国家均连续，总发展度保持 106。
- B19 福建：十三省正式像素边界与配套资产已部署；厦门的编号、RGB和29个手绘像素保持不变。
- B22 云南：二十六省正式像素边界及定义、历史、区域、地形、贸易、位置和本地化已部署；新增编号为 `5224–5241`。
- B23 山西：二十个可通行省、四个五省区域及五块不可通行山地已正式部署；总发展度为202，曲沃作为独立省份实装。
- 实机验证：旧版 B01 已完成初步验证；八省版仍应在新游戏中复核。

正式地图的唯一几何源是
`guangdong_independent_practice/map/provinces.bmp`。任何边界调整都应直接在该文件中
手绘；预览图、候选多边形和生成器配置不得反向覆盖它。归属、发展度、ID 或 RGB
调整则应同步更新总表、CSV 与正式游戏资产。
