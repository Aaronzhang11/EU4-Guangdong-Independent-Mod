# 地图设计资产

本目录保存《列国奉周》的地图源数据和绘制规范。设计文档与游戏实现必须分开标记；没有通过分区审图和实机验证的地图不得宣称已经完成。

## 当前文件

1. [中华大区拆省总表](01_china_province_split_master.md)：四十一个新增省份的母省、归属、理由与发展度分配。
2. [分区绘制计划](02_regional_drawing_plan.md)：九个绘制批次、锚点、风险和交付门槛。
3. [B01 广东拆省审图记录](03_b01_guangdong_review.md)：首批五省的像素边界、冻结分配和静态验证结果。
4. [可机读拆省登记表](china_province_split_registry.csv)：供 ID、RGB、历史和验证脚本使用的 CSV 源数据。
