# B53 诸夏篆书国旗

## 范围

以 `apply_culture_overhaul.py` 中的十二个 `HAN_CULTURES` 为“诸夏”权威范围。B54 后共识别 59 个国家；长沙（CSA）保留既有参考旗，其余 58 面由脚本生成。

吴、闽、广府、壮、宋卫、东夷、氐羌及非汉文化国家不在本批范围内。南海（GDD）作为风格参考保留原旗，不因本批被改写。

## 视觉规则

- 保留各国原旗的主色，避免诸夏国家在地图上失去辨识度。
- 使用《说文解字》小篆字形；浅色底旗改用深墨色。
- 一字国号居中放大；二字国号仿照长沙、南海横排。
- 去除旧批次的对角线占位纹样，统一为长沙、南海一类的纯色大字构图。
- 旗面统一使用传统字形；“魏”“沃”按“委+鬼”“水+夭”的小篆结构合成。

## 重放与验证

```bash
python3 tools/generate_zhuxia_seal_flags.py
python3 tools/generate_zhuxia_seal_flags.py --check
```

生成器读取已固化的小篆字形蒙版，不分发字体文件，也不依赖运行机器安装该字体。B43、B50、B52 国家生成器会在写入国家旗帜后重新应用本标准，避免重放时退回占位旗。

字形来源：数位发展部，CNS11643 中文标准交换码全字库网站，https://www.cns11643.gov.tw 。
