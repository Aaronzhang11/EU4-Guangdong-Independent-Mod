# 中华大区分区绘制计划

## 目的

本文规定在[中华大区拆省总表](01_china_province_split_master.md)通过审校后，如何把七十五个新增省份逐区绘制到 EU4 1.37.5 地图上。

当前状态是**广东、东南、江西、湖南与浙江的正式几何均已写入模组并通过静态
校验**。75 个新增省份的数字 ID 与 RGB 已冻结；湖北扩展使用 `4981` 与
`5008–5016`，正式地图的 `max_provinces` 为 `5017`。

## 总体边界原则

1. 第一轮保持原版陆海轮廓不变，不修改海岸线、岛屿形状和湖泊。
2. 新省只能从总表登记的母省内部切出；跨母省调整必须先回写总表。
3. 边界依据优先级为自然地理、传统城镇腹地、本世界线政治史、玩法需求、现代行政界参考。
4. 正式栅格不得使用抗锯齿、透明度或模糊笔刷。
5. 禁止单像素颈部、只靠对角线接触的“邻省”、难以点击的细长条和无理由飞地。
6. 港口省拆分时必须保留足够海岸像素；不需要港口的新省不应意外取得海岸。
7. 草图、遮罩和候选多边形可以辅助审图，但正式边界必须由用户写入唯一几何源
   `guangdong_independent_practice/map/provinces.bmp`；自动化工具只允许读取并校验它，
   不得用预览结果覆盖它。

## 各批次绘制提示

### B01 广东

- 先锁定广州 667 的城市点、港口点、文字点、南海神庙和珠江口修正。
- 佛山从广州西南腹地切出，不夺取广州主港。
- 在行政与发展度核算上，惠州—东莞—香港—陆丰构成一个四省组；手绘几何允许
  结合广州、惠州旧边界整体重划，不再受原版单一母省轮廓限制。
- 东莞位于惠州西南、珠江口东岸，需要取得虎门方向海岸，但不能把惠州切成狭长残片。
- 香港位于东莞东南，以新界—九龙沿岸作可点击的前现代港湾省；本轮不修改原版海岸线，因此岛屿与港湾采用栅格抽象。
- 梅州从潮州西北内陆切出；绘图结果应允许潮州归闽、梅州归粤。
- 高州位于雷州半岛根部，雷州必须继续保有海峡门户。
- 罗定从肇庆南部切出，保持完整内陆轮廓并连接粤西腹地，不得意外获得海岸。
- 南雄从韶关东北切出，表现梅关古道南口，并维持韶关与湖南方向的正常邻接。
- 陆丰位于惠州以东、潮州以西的海岸，必须保有清楚的海岸线和可用港口，同时
  不能吞并潮州主体。

### B02 秦地与西陲

- 同州应体现关中东部和潼关后方，不能切走西安城市点。
- 金州沿汉水和安康盆地布置，必须保留汉中盆地的完整主体。
- 敦煌与玉门都要成为可点击的绿洲节点，荒漠面积不等于发展度。
- 河州需要核对兰州、洮州和西宁三向邻接，避免产生意外山地捷径。

### B03 中原与淮北

- 洛阳城市点留在 1836；陕州构成西部门户。
- 荥阳位于洛阳—开封之间，应产生真正的边境纵深而不是细长隔离带。
- 宿州从徐州南部切出，既要连接商宋核心，也要形成与淮扬盟的争议边。

### B04 河北与山西

- 邢州的单母省方案目前使用 2137；若历史城点落在 4195，应先修改登记表再画。
- 沧州应取得盐运或沿海功能，但不得误吞山东海岸。
- 汾州和蒲州分别代表汾河中游与河东南部，不能把太原、平阳残留省切得过小。

### B05 山东与鲁礼邑

- 登州取得胶东半岛北端海岸，莱州保有内湾主体。
- 聊城向山东西部展开，不得切断济南与齐国其他核心的陆路。
- 曲阜应围绕礼邑城市点形成紧凑省份；孔庙与相关永久修正随之迁移。

### B06 江南、江淮与浙江

- 江苏十八省已经落图。徐淮海州七省以沂沭河、黄运河故道、洪泽湖—淮河和
  串场河为主要界线；淮扬通泰五省依高邮湖、京杭运河、通扬运河及长江北汊
  收边；金陵吴会六省参考茅山、太湖水网、运河与长江南岸建制。
- 各子省主体面积控制在 `138–165` 像素，内陆省均为单一连通块；边界避免
  长直线、直角折返、细颈和狭长楔形。松江的额外离岸块只表现真实江海岛洲。
- 芜湖母省宁国像素较小；若无法同时保留两块可用省份，应改从安庆或南京方案重新论证。
- 浙江十四省已经落图：府界骨架参考 CHGIS V6 1820 年府州边界，内部再按钱塘江、
  新安江、甬江、瓯江水系及天目、天台、括苍、洞宫诸山调整为连续曲线。
- 昌国仅取舟山群岛最外海两组岛屿，近岸两组大岛归宁波；宁海沿象山港—天台
  山东麓切分；义乌位于金衢盆地东段。边界避免直角、长直线和突兀折返。
- 昌国与宁波之间必须保留明确水道，不能依靠陆地像素直接相邻；通行由经东海
  海区 `1373` 的正式海峡邻接承担。

### B07 江西与湖广

- 九江围绕鄱阳湖出口，不能切断南昌通往赣北的所有陆路。
- 江西内部边界以 CHGIS V6 的 1820 年府界为历史骨架：九江、南昌、饶州围绕
  鄱阳湖重新收边，赣江保留为贯穿南昌—吉安—赣州的城市走廊，瑞州、袁州、
  广信和临川之间则参考罗霄山、武夷山及其支流水系形成曲折边界。
- 汉阳与武昌分置长江两岸时，不能形成单像素河岸或不可点击楔形。
- 岳州围绕洞庭湖出口，同时为楚湘双方制造可理解的边境。
- 湖南按洞庭湖、湘中、湘西南岭三个四省 Area 实装；长沙保留政治首都，岳州和
  衡州承担两个一级贸易中心。
- 湖南内部边界以 CHGIS V6 的 1820 年府州轮廓为历史骨架，并结合原版河流图层
  调整为曲折边界：洞庭湖区参考湘、资、沅、澧四水汇流，湘西侧重武陵—雪峰
  山地，湘南侧重南岭与湘桂、湘赣谷地；主河流作为城市走廊时不强行充当省界。
- 靖州必须接触贵州或广西方向，永州承接桂林通道；郴州必须接触赣南、南安或
  南雄方向，并承担南岭要塞。

### B08 福建、广西与台湾

- 莆田、漳州均需拥有清楚的湾区和沿海空间，不能把福州、泉州港口点切走。
- 浔州沿黔江—浔江节点布置，不应虚构贯穿山地的直线通道。
- 诸罗不预设越国殖民；绘图只确定空间，国家和文化另行决定。

### B09 巴蜀与云贵

- 成都、眉州、嘉州、雅州之间应体现盆地—山口层次。
- 万州属于巴国峡江走廊；夔州、宜昌方向的边界必须结合原版 681 省检查。
- 昆明母省一次拆成昆明、楚雄、东川三块，是本批风险最高项目。
- 永昌必须保留通向缅甸方向的边关语义；安顺应成为贵阳西部而非孤立飞地。

## 每批交付物

每个绘制批次依次交付：

1. 原版母省裁切图。
2. 带设计键、城镇锚点和候选边界的审图 PNG。
3. 新旧省份面积与邻接清单。
4. 港口、城市、文字和奇观锚点检查。
5. 母省发展度拆分复核。
6. 用户确认后直接写入正式 `provinces.bmp` 的无抗锯齿手绘边界。
7. 该批次的静态验证报告。

## 从手绘到正式落图的统一门槛

新增省份 ID 与 RGB 已预先冻结，避免各批次互相碰撞。B01 的手绘位图已经成为正式
唯一几何源；B02—B09 也必须沿用同一原则。每批边界确认后执行以下正式落图动作：

- 锁定 EU4 1.37.5 为地图基线。
- 复核八十四个设计键的连续数字 ID 和唯一 RGB。
- 保留已经冻结的 `4942–5025` 编号与 RGB；后续新增省份从 `5026` 接续，
  不回收或改写已经落图的颜色。
- 更新 `definition.csv` 与 `default.map`。
- 生成或更新 area、region、continent、climate、terrain、trade node、positions、历史和本地化。
- 对所有旧省份硬编码引用进行迁移审计。
- 对正式 `provinces.bmp` 只做像素、色彩、连通性和 BMP 格式校验，不从任何候选几何重新生成。

## Area 重组候选

第一轮拆分后，下列旧 area 将达到七至八省，正式落图时宜拆分或重组：

- `shandong_area`：5 → 8；
- `shanxi_area`：5 → 7；
- `zhejiang_area`：5 → 7；
- 原 `guangdong_area` 覆盖范围：5 → 11（现拆为珠江三角洲 5 省与广东 6 省）；
- `yun_gui_area`：5 → 8。

Area 重组不能只追求每组数量相等，还要考虑各诸侯的州界、贸易节点和治理成本。

广东建议把广州、澳门、佛山、东莞、香港组成珠江口 area 候选；把惠州、陆丰、
潮州、梅州方向另组粤东 area；韶关、南雄与罗定的最终 area 归属还须结合南岭通道、
粤西交通和诸侯边界复核。
