# B18 四川三十六省正式细化

本批次将审核通过的县级 GeoJSON 辅助草图正式写入游戏地图。边界覆盖成都盆地、川北、川南、巴东、松茂、阿坝、甘孜和凉山；四川以外像素不参与替换。

## 九个区域

| 区域 | 省份 |
| --- | --- |
| 成都 | 成都、灌州、邛州、眉州 |
| 嘉雅 | 嘉州、雅州、黎州 |
| 川北 | 绵州、剑州、阆中、顺庆、达州 |
| 川南 | 资州、富顺、叙州、泸州 |
| 巴东 | 重庆、合州、涪州、万州、夔州 |
| 松茂 | 松州、茂州、汶川、南坪 |
| 阿坝 | 马尔康、金川、阿坝、若尔盖 |
| 甘孜 | 康定、德格、壤塘、理塘 |
| 凉山 | 嶲州、会理、盐源 |

## 游戏性设置

- 成都与重庆为二级贸易中心，松州与康定为一级贸易中心。
- 剑州、夔州、松州、嶲州设置十五世纪要塞。
- 成都平原以丝绸、布匹、谷物和茶叶为主；川南突出井盐；甘孜、阿坝和松茂以牲畜、羊毛、茶叶和纸张为主；凉山配置谷物、铜矿和盐。
- 新增省份使用 `5075–5095`，`max_provinces` 调整为 `5096`。

## 技术说明

- 正式几何来源：`planning/sichuan_36_province_draft.bmp`。
- 应用脚本：`tools/map_pipeline/apply_sichuan_refinement.py`。
- 脚本同步更新定义、历史、区域、位置、本地化、气候、洲、贸易节点与贸易公司数据。
- GeoJSON 栅格化形成的一至三像素孤点会自动并入相邻四川省份；可通航长江造成的较大分离岸段保持不动。
