# B22 云南二十六省 GeoJSON 细化

本批次以现代云南县级 GeoJSON 为几何辅助，并按明清府州、横断山系、金沙江—元江—澜沧江流域和游戏省份连续性进行归并。正式地图由原八省扩展为二十六省、六个区域。

## 六个区域

| 区域 | 省份 |
| --- | --- |
| 滇西北 | 德钦、独克宗、丽江、剑川 |
| 滇西 | 泸水、大理、永昌府、德宏 |
| 滇中 | 楚雄、昆明、新兴州、东川 |
| 滇东 | 乌蒙、芒部、沾益、曲靖 |
| 滇西南 | 勐缅、耿马、思茅、镇沅、勐连 |
| 滇南 | 版纳、勐腊、蒙自、红河、广南 |

## 游戏性与经济

- 开局总发展度为 150；昆明 13、大理 12，是两处最成熟的盆地核心。
- 昆明与大理各设二级贸易中心，不再额外增加第三个贸易中心。
- 铜、铁集中于昆明—东川、曲靖和广南；滇西、滇南以茶叶、热带木材、牲畜和粮食形成互补。
- 德钦—独克宗使用藏文化和金刚乘；大理—昆明腹地以白文化、佛教为主；乌蒙和红河山地以彝文化、原始宗教为主；边境傣掸走廊采用掸文化、佛教。
- 保留原版 1444 政治格局：大部分省份由明控制，德宏、版纳及西南边境土司暂随孟卯，并在 1449 年转入明朝历史线。该设置不提前替代未来世界线国家标签设计。

## 编号与地图连续性

- 保留八个既有编号：`660`、`661`、`662`、`663`、`675`、`2165`、`2166`、`2167`。
- 新增十八个编号：`5224–5241`；`max_provinces` 提升为 `5242`。
- 草图产生的新兴州、乌蒙微型飞地分别归并楚雄、芒部。
- 思茅与镇沅的两处交错县级飞地互换归并，使全部二十六省均为单一连续地块。
- 新省分别加入成都或广州贸易节点及相应贸易公司，不存在重复贸易节点归属。
