# 《列国奉周》（开发中）

《欧陆风云 IV》中国地区架空历史与地图重制 MOD。项目最初以广东独立玩法为核心，现已扩展为“秦未统一、周室延续、诸夏列国并立”的 1444 年世界线。

仓库与启动器中的技术名称仍为 `Guangdong Independent Practice`；当前世界观工作名为《列国奉周》。广东（`GDD`，游戏内国号“南海”）仍是专属内容最完整的可玩国家之一。

## 当前状态

| 项目 | 当前值 |
|---|---|
| MOD 版本 | `1.0` |
| 描述器支持版本 | Europa Universalis IV `1.37.*` |
| 地图制作基线 | Europa Universalis IV `1.37.5` |
| 推荐开局 | 1444 年 11 月 11 日新游戏 |
| 开发阶段 | 可运行的开发／测试版本 |

本 MOD 会替换中国地区的省份、国家历史、文化、贸易、通航水域、地形和部分界面文件。请勿使用旧存档测试，也不要与其他修改中国地图或中国开局的 MOD 同时启用。

## 世界观

秦国未能完成统一，周室以礼制共主的身份延续至近世。诸侯国并不是从先秦原样冻结到 1444 年的古代标本，而是在两千年的战争、迁徙、册封、兼并与复国中不断演变的地域政权。

1444 年的诸夏共享朝会、盟誓与礼制，却各有军队、财政和外交利益。周天子仍主持名义上的天下秩序，秦、燕、齐、楚、蜀、巴、吴、越、闽、南海、辽等大诸侯与大量小国、公邑和边疆政权共同构成分裂的中国。

世界观设定和游戏实现并不完全同步。`docs/` 记录正典与设计方向，真正已经进入游戏的内容以 `guangdong_independent_practice/` 下的加载文件为准。

## 已实现的主要内容

### 周天下原型系统

仓库已经包含一套不占用欧洲神圣罗马帝国容器的“周天下”脚本系统：

- 周国 `CZH` 为当前天子，诸侯以独立成员身份登记，不是天子的普通附庸；
- 使用明确的国家名单维护普通成员与主要诸侯，并为旧版本系统提供存档迁移；
- 以 `-100` 至 `100` 的“礼乐值”表示共同秩序，划分为纲常有序、礼制稳固、礼乐相持、礼教废弛、礼崩乐坏五档；
- 礼乐值会根据天下和平、诸侯战争、天子稳定度、威望、厌战和首都控制等条件进行年度结算；
- 天子可以召开开封大朝会，成员可以奉行王礼并积累盟功；
- 已实装第一项盟约改革“重申成周盟书”；
- 已实装“王命不行”天下事变：诸侯进行为期约一年的公议，可赞同、反对、弃权并在结算前改票；
- “诸夏王会”专属界面可查看天子、礼乐值、秩序阶段、天下事变、盟约改革和动态成员名册；
- 决议页提供周天下疆域高亮入口，界面不可用时仍可通过事件总览读取状态。

这套系统目前是可玩的纵向原型，而不是最终完整版。方伯推举、多轮盟约改革、复国规则、共同防御和制度终局仍待完成。

### 1444 年列国格局

中国开局已经从少数大国重构为大诸侯、小国、附庸和公邑并存的政治地图，包含：

- 周、秦、燕、齐、楚、蜀、巴、吴、越、闽、宋、徐、赵、魏、代、鲁、陈、蔡、义渠等列国；
- 楚国及鄂、权、州附庸体系，长沙也作为楚国的开局附庸；
- 辽国及契丹文化，海南黎国及琼黎文化；
- 淮、瓯、衡等区域小国，以及扬、芜、舟、常、九、汉等通商公邑或单省共和国；
- 西南、西北和边疆地区的白马弥药、巴氐、宕渠、枳、南诏、蒙古大理等政权；
- 大批国家定义、1444 年历史、首都、核心、外交关系、军队、国旗和中文本地化；
- 统一风格的诸夏小篆国旗，辽国另使用契丹文字印章方案。

并非所有国家都已经拥有专属理念、任务和事件。目前最完整的国家级内容仍集中在南海，其他列国主要完成了地图、国家资料和周天下身份层。

### 中国地图重制

正式地图已经细化广东、福建、浙江、江西、湖南、湖北、河南、安徽、江苏、四川、重庆、贵州、云南、山西、山东、河北、陕西、甘肃—宁夏、广西、海南和辽宁等区域。

地图改动包括：

- 新省份的像素边界、ID、定义色、历史、发展度、贸易品、文化与宗教；
- Area、Region、气候、地形、城市、港口、部队和文字位置；
- 长江、淮河与邗沟等可通航水域及相应特殊邻接；
- 山西、秦蜀、西北等地的战略山脉与不可通行地形；
- 自定义 `terrain.bmp`、`trees.bmp` 及配套 DDS 地形资源；
- 洛阳宫殿与阿房宫地图 3D 模型；
- 对不符合世界线的帝号、现代行政名和错位地名进行统一校正。

中华核心贸易网络已经重构为八个节点：

| 节点 | 大致范围 | 定位 |
|---|---|---|
| 吴越 | 江浙、皖江、江淮 | 中国内部唯一终点节点 |
| 百越 | 闽粤桂、海南、台湾及安南 | 南海入口 |
| 荆楚 | 湖北、湖南、江西 | 长江中游汇流 |
| 巴蜀 | 四川、重庆 | 长江上游节点 |
| 滇夜郎 | 云南、贵州 | 西南入口 |
| 秦陇 | 陕西、甘肃、宁夏 | 西北汇流 |
| 河济 | 河南、山东、冀南 | 黄淮汇流 |
| 幽燕 | 河北、山西、辽西及赵地 | 北方汇流 |

八个特许贸易区与对应节点的陆地边界同步调整；广州是当前唯一的三级开局贸易中心。

正式游戏地图的唯一几何权威是 `guangdong_independent_practice/map/provinces.bmp`。`planning/` 中的预览、备份、GeoJSON 和候选图不能直接替代它。

### 文化、姓名与旗帜

中国文化结构已经重新划分为诸夏、百越、殷商、羌等文化组，并细化中原、江淮、楚、赣、客家、桂、蜀、滇、晋、齐、燕、陇、粤、吴越、闽越、宋卫、东夷、氐羌等文化；另有琼黎与契丹等新增文化。

仓库同时包含按文化分配的中文君主、人物和王朝姓名池，以及用于生成、编码和检查中文国家脚本与本地化的工具。可读 UTF-8 源文件保存在 `guangdong_independent_practice/localisation_source/`，游戏加载文件则使用 EU4 中文编码格式。

### 南海（广东）玩法

南海 `GDD` 以广州为首都，使用粤文化并接受客家与闽越文化。现有专属内容包括：

- “岭南自立”1444 年书签；
- 梁守谦、梁守毅及后续继承人事件，含专属人物特性；
- 开局 11,000 陆军、8 艘舰船、三名低价二级顾问；
- 与明国五年停战及停战到期后的续约／战争事件链；
- 开局自动授予“宗族自治特许”和“南粤的贸易特许”两项阶层特权；
- 以南洋殖民、海贸、水手、整合、纪律和生产为核心的国家理念；
- 军事、外交、朝廷、首府、贸易、货币与市场任务；
- 广州一级奇观“南海神庙与扶胥古港”，可通过稳定、贸易中心和南洋港口条件升级；
- 七类通用新顾问：政务改革家、行政组织家、交际花、舰队建造官、拓殖宣传家、行军参谋和战术家。

旧文档中出现过的“奉贡藩国”“王朝藩属”和“脱离华夏”不属于当前版本的现行南海玩法，请以本节和实际加载脚本为准。

### 天命代行试验系统

除周天下原型外，仓库还保留一套独立的中华帝国界面试验：

- 在原天命界面中加入“代行圣旨”和“推动改革”入口；
- 天子或当前测试用首席诸侯燕国可以代为选择圣旨或推动天朝改革；
- 自定义脚本扣除贤能值、天命与稳定度，并向天子和天朝成员施加对应效果；
- 原版圣旨、改革显示与自定义状态共同保留。

这是用于验证“诸侯干预天命”交互的测试功能，目前首席诸侯固定为燕，并不等同于已经完成的周天下方伯制度。

## 安装

将以下两个项目复制到 EU4 用户 MOD 目录：

```text
文档\Paradox Interactive\Europa Universalis IV\mod
```

- `guangdong_independent_practice.mod`
- `guangdong_independent_practice` 文件夹

安装后的结构应为：

```text
Europa Universalis IV\mod\
├─ guangdong_independent_practice.mod
└─ guangdong_independent_practice\
```

随后在 Paradox 启动器的同一播放集内启用：

1. `Chinese Language Mod for 1.37`
2. `Chinese Language Supplementary Mod for 1.37`
3. `Guangdong Independent Practice`

建议关闭其他会修改中国地图、开局历史、文化、贸易节点或天命界面的 MOD，并从 1444 年开始新游戏。

## 兼容性

- 描述器标记支持 EU4 `1.37.*`，地图和工具链以 `1.37.5` 为基线；
- 依赖两个 1.37 中文汉化 MOD；
- 不兼容随机新世界地图设置；
- 不兼容旧存档；
- 大概率不兼容其他中国地图、国家开局、贸易、文化、通航水域或天命界面 MOD；
- 描述器没有声明 DLC 硬依赖，但人物特性、繁荣度、奇观、天命等内容会按对应 DLC 是否存在而启用、降级或不可用。

## 开发与验证

地图修改必须从全新 1444 年游戏开始实机测试。静态检查不能替代引擎内的地图、寻路、界面和存读档验证。

常用检查命令：

```powershell
python tools\map_pipeline\validate_b01_mod.py --vanilla-root "<EU4 1.37.5 安装目录>"
python tools\encode_eu4_chinese_localisation.py --check
python tools\generate_zhuxia_seal_flags.py --check
python tools\map_pipeline\apply_b49_eight_node_trade_network.py --check
python tools\map_pipeline\finalize_zhx_province_history.py --check
python tools\build_zhx_academy_lifecycle.py --check
python tools\validate_zhx_academy_lifecycle.py
git diff --check
```

注意：

- 修改 `provinces.bmp` 后应同步核对 `definition.csv`、省份历史、Area、Region、地形、气候、贸易、位置、特殊邻接和本地化；
- `provinces.bmp`、DDS、TGA 和模型文件属于二进制资产，Git 冲突不能逐行合并；
- 不要用旧预览图或早期生成器覆盖正式 `provinces.bmp`；
- 中文游戏文件不能由普通 UTF-8 格式化器批量改写，应修改 `localisation_source/` 中的可读源并使用项目编码脚本；
- 重放早期地图批次后，需要按依赖顺序重跑后续平衡、贸易和旗帜脚本；所有省份历史
  writer 结束后，最后运行 `tools/map_pipeline/finalize_zhx_province_history.py`，并紧接
  `--check`，恢复并锁定宗教地理与具名学宫落点。

## 已知未完成项

- 周天下仍缺少正式方伯推举、完整盟约改革树、共同防御、非法吞并／复国和多路线终局；
- 大多数列国尚无完整的专属理念、任务、事件和 AI 行为；
- “王命不行”是当前唯一完整天下事变，其他区域与全国事变仍在设计；
- 天命代行界面的首席诸侯仍固定为燕国测试位；
- 全国地图、3D 模型、通航水域和自定义界面仍需持续进行不同分辨率、DLC 组合和长期观察局验证。
