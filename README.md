# Guangdong Independent Practice

《欧陆风云4》广东独立架空历史MOD。

## 当前版本

v0.4

## 世界线扩展计划

项目正在规划升级为“秦未统一、周室延续、诸夏列国并立”的大型架空历史模组。当前广东内容将作为周盟中的岭南诸侯继续保留。

世界观、列国方案和技术设计统一收录在 [`docs/README.md`](docs/README.md)。文档规划不代表相关内容已经进入当前 v0.4 版本。

## 主要内容

- 1444年广东独立开局
- 控制除潮州外的广东、海南和澳门
- 正式细化广东地图，新增佛山、东莞、梅州、高州和香港五省
- 珠江口重组为独立 Area；香港以1444年的屯门锚地和海防港湾表现
- 广东专属国家理念
- 专属君主、继承人与初始顾问
- 初始11k陆军与8艘舰船
- 广东专属开局背景
- 与明朝保持特殊宗属关系、初始五年停战及后续和约事件链
- 梁守谦专属“岭南王”称号与服众、安民、肃贪三项特性
- 奉贡藩国的锁定一级改革“地方藩国”
- “脱离华夏—大逆不道”事件链、国家决议与讨伐违制藩国借口

## 兼容版本

- Europa Universalis IV v1.37.*
- 当前地图基线锁定 Europa Universalis IV 1.37.5
- 当前版本面向中文汉化环境
- 不保证兼容修改中国地图、开局历史或开局介绍的其他MOD

## 安装方法

将以下两个项目放入：

`文档\Paradox Interactive\Europa Universalis IV\mod`

- `guangdong_independent_practice.mod`
- `guangdong_independent_practice`文件夹

随后在Paradox启动器中启用MOD，并开始一个新的1444年游戏。(只打开该mod和两个中文翻译包)

## 已知问题

- 奉贡藩国机制仍在开发和测试。
- “讨伐违制藩国”暂不免除撕毁停战、军事通行权等额外外交稳定度惩罚。
- 部分人物、顾问及开局内容可能继续调整。
