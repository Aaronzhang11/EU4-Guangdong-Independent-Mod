# Guangdong Independent Practice

《欧陆风云4》架空历史MOD。

## 当前版本

v0.5

## 主要内容

- 1444年周天下开局
- 正式细化广东、福建、江西地图，新增佛山、东莞、梅州、高州、香港、罗定、南雄和陆丰八省
- 广东范围现有十八省：GDD控制十七省，潮州由乡绅控制并保留GDD宣称
- 珠江口重组为独立 Area；香港以1444年的屯门锚地和海防港湾表现
- 罗定以泷水县腹地表现；南雄表现梅关商路；陆丰以碣石卫、海盐与粤东海防表现
- 南海专属国家理念
- 专属君主、继承人与初始顾问
- 初始11k陆军与8艘舰船
- 南海专属开局背景
- 与周王保持特殊宗属关系
- 梁守谦专属“南海侯”称号与服众、安民、肃贪三项特性
- 封国的锁定一级改革“王朝藩属”
- “脱离华夏—大逆不道”事件链、国家决议与讨伐违制藩国借口

## 兼容版本

- Europa Universalis IV v1.37.*
- 当前地图基线锁定 Europa Universalis IV 1.37.5
- 当前版本面向中文汉化环境
- 不保证兼容修改中国地图、开局历史或开局介绍的其他MOD

## 安装方法

将以下两个项目放入：

`文档\Paradox Interactive\Europa Universalis IV\mod`

- `guangdong_independent_practice.mod`
- `guangdong_independent_practice`文件夹

随后在Paradox启动器中启用MOD，并开始一个新的1444年游戏。(只打开该mod和两个中文翻译包)

## 已知问题

- 奉贡藩国机制仍在开发和测试。
- “讨伐违制藩国”暂不免除撕毁停战、军事通行权等额外外交稳定度惩罚。
- 部分人物、顾问及开局内容可能继续调整。
- v0.5手绘地图已经通过静态校验，但罗定、南雄和陆丰仍需使用全新1444年游戏完成本轮实机验证。
