# Guangdong Independent Practice

《欧陆风云 IV》架空历史与中国地图改造 MOD。项目以广东为主要可玩切片，并逐步扩展为“秦未统一、周室延续、诸夏列国并立”的《列国奉周》世界线。

## 项目状态

- MOD 版本：`1.0`
- 支持版本：Europa Universalis IV `1.37.*`
- 当前地图基线：Europa Universalis IV `1.37.5`
- 当前阶段：开发与测试版本
- 推荐开局：1444 年 11 月 11 日新游戏

本项目会修改国家、开局历史、省份、区域、贸易、通航水域和地形资源，因此不兼容旧存档，也不保证兼容其他修改中国地图或中国开局的 MOD。

## 世界观

在本世界线中，秦国未能统一六国，周室作为礼制共主延续至 1444 年。诸夏各国在共同礼制下长期并立，拥有各自的政治传统、外交利益与地区认同。

当前可玩内容以广东为核心，并已经加入周、潮州、宋及其他列国相关的国家定义和开局历史。《列国奉周》的完整十八国、周盟、方伯和天下事变体系仍在持续设计与实现中；`docs/` 中的设定文档不等于所有内容都已写入游戏。

## 当前已实现内容

### 广东玩法

- 广东国家 `GDD`，当前本地化国号为“南海”
- 1444 年专属统治者梁守谦、继承人及人物特性
- 专属开局事件、背景和广东—宗主关系初始化
- 开局 11,000 陆军与 8 艘舰船
- 锁定的一级政府改革“王朝藩属”
- 自定义“奉贡藩国”属国类型，拥有有限外交自主权且不占宗主外交关系
- 广东专属国家理念，侧重南洋殖民、贸易、海员、生产与岭南扩张
- “脱离华夏”决议及配套事件链
- 军事、外交、内政、贸易与市场建设任务
- 广州“南海神庙与扶胥古港”奇观
- 专属君主、继承人与初始顾问内容

### 通用顾问

新增七类可由所有国家使用的顾问：

- 政务改革家
- 行政组织家
- 交际花
- 舰队建造官
- 拓殖宣传家
- 行军参谋
- 战术家

这些顾问使用原版顾问肖像池，不需要额外肖像资源。

### 国家与开局

- 自定义 1444 年书签，以广东和周为主要观察对象
- 新增或调整广东、周、潮州、徐、宋、齐、燕等国家的开局资料
- 新增宋国 `SNG` 的国家定义、历史与标签
- 调整部分国家的部队和地图位置

### 中国地图

项目已经完成多轮中国地图细化，涉及广东、福建、江西、浙江、湖南、湖北、河南、安徽、江苏、四川、重庆、贵州、云南、山西、山东、河北、陕西、甘肃—宁夏、海南、辽宁和广西等区域。

地图内容包括：

- 新省份、定义色、历史、区域与地区归属
- 发展度、贸易品、文化、宗教、气候与地形配置
- 省份城市、港口、部队和文字显示位置
- 长江、淮河与邗沟等可通航水域
- 广州贸易节点及多地贸易流向调整
- 汉中、西北等地的战略山脉与地形连续性处理
- 新的 `terrain.bmp`、`trees.bmp` 和地形 DDS/BMP 视觉资源

正式游戏地图的几何源以 `guangdong_independent_practice/map/provinces.bmp` 为准。`planning/` 中的草稿、预览与备份不能直接替代正式地图。

## 安装方法

将以下两个项目复制到：

```text
文档\Paradox Interactive\Europa Universalis IV\mod
```

- `guangdong_independent_practice.mod`
- `guangdong_independent_practice` 文件夹

安装后的结构应类似：

```text
Europa Universalis IV\mod\
├─ guangdong_independent_practice.mod
└─ guangdong_independent_practice\
```

随后在 Paradox 启动器中启用：

1. `Chinese Language Mod for 1.37`
2. `Chinese Language Supplementary Mod for 1.37`
3. `Guangdong Independent Practice`

建议只启用本 MOD、上述两个中文依赖以及确认兼容的界面类 MOD，然后开始一个全新的 1444 年游戏。

## 兼容性

- 支持版本按描述器标记为 EU4 `1.37.*`
- 当前地图制作与验证基于 EU4 `1.37.5`
- 依赖两个 1.37 中文汉化 MOD
- 不兼容随机新世界地图设置
- 不兼容旧版本存档
- 大概率不兼容其他修改中国省份、区域、贸易节点、通航水域或开局历史的 MOD
- 部分人物特性和政府功能会根据所拥有的 DLC 使用不同效果或降级处理

## 仓库结构

| 路径 | 用途 | 安装游戏时是否需要 |
|---|---|---:|
| `guangdong_independent_practice.mod` | Paradox MOD 描述器 | 是 |
| `guangdong_independent_practice/` | 游戏实际加载的 MOD 内容 | 是 |
| `docs/` | 世界观、玩法和地图设计文档 | 否 |
| `planning/` | 地图草稿、预览、源数据和修改前备份 | 否 |
| `tools/` | 地图构建、检查与本地化处理脚本 | 否 |

普通玩家只需要复制描述器和 MOD 文件夹，不需要复制 `docs/`、`planning/` 或 `tools/`。

## 开发与测试注意事项

- 修改地图后必须开始新游戏测试，不能使用旧存档判断结果。
- 调整 `provinces.bmp` 时应同步检查 `definition.csv`、省份历史、区域、地形、贸易、位置和本地化。
- 地图中的 BMP 与 DDS 是二进制文件，发生 Git 冲突时不能逐行合并。
- `planning/` 中部分文件是地图脚本的输入或历史备份，清理前应先检查 `tools/map_pipeline/` 中的引用。
- 中文本地化使用 EU4 特有的编码形式，不应由普通文本格式化工具批量改写。
