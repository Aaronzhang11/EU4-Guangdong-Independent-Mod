# 舟国小篆旗字形来源

- 国别：舟国（`ZHO`）
- 旗面文字：舟
- 字形：教育部《异体字字典》收录的《说文解字》小篆字形
- 条目：https://dict.variants.moe.edu.tw/dictView.jsp?ID=-37163
- 原图：https://dict.variants.moe.edu.tw/rbt/sword/sworda/sa03410/001_a.jpg
- 原图 SHA-256：`0fe8786b12c637133bf4d31fa8cd58beab7e0dda36e7d52430f59b0935dc1685`

生成器仅反相、清除 JPEG 浅色压缩噪点、提高笔画不透明度、等比例缩放并居中；不使用现代字体重绘，也不补笔。旗底沿用舟国定义中的 `{ 183 168 75 }`，文字沿用诸夏篆书旗的浅帛色。
